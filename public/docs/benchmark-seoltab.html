설탭(Seoltab) 벤치마크 리포트

조사일 2026-07-06 · 대상: index.seoltab.com 전 페이지 · 사이트 전면 개편(설탭 구조 이식)의 기준 문서

1. 전환 설계 핵심 10가지

  1. 단일 전환점 = 상담신청. 모든 CTA(히어로·선생님 카드 "빠른 매칭받기"·FAQ 하단)가 상담신청 한 곳으로 수렴.
  2. 초저마찰 폼. 이름조차 받지 않음: 학년 + 과목 + 연락처 + 희망 시간 + 약관. "5초면 충분"을 카피로 반복.
  3. 리스크 제거 3종. 첫 수업 후 100% 환불 / 선생님 무료 변경(+무료수업 추가) / 상담만 해도 학습진단 무료.
  4. 하단 고정 CTA. 전 페이지에서 추천받기 버튼 + "첫 수업 후 불만족시 100% 환불" 툴팁이 상시 고정.
  5. 상단 긴급성 배너. 상담 대기 연출 + 바로 결제 우회로.
  6. 숫자 증거 반복. 만족도 97%·2명 중 1명 성적 상승·합격률 53.3%·누적 카운트업. 전 수치에 조사 기준 각주.
  7. 성적 변화 정형 표기. "4등급 → 1등급!" 화살표 + #과목 #전형 #대학 해시태그.
  8. 실물 증거 인증. 합격통지서·성적표 스캔 + 학생 사진·코멘트 오버레이.
  9. 학부모 안심 장치. 매니저 중개(안심리뷰·월간 리포트·상담) + 학부모 화법 후기.
  10. 가격 앵커링. 요금표 대신 "월 199,000원~" 한 줄, 나머지는 상담으로.

2. 페이지별 섹션 구조

메인(/)

긴급성 배너 → 시즌 캠페인 히어로(모델 사진) → 명예의전당 캐러셀 → 선별·매칭·관리 책임 3단계 → 변경 보장 → 수업 모니터링 → 내신 프로그램 → 무료 학습컨설팅 브릿지 → 100% 환불 밴드 → 만족도 → 서비스 소개 → 내신 상세(전략→수업→리뷰) → 질문 교수법 → 인강 번들 → 성적상승 통계 → 학부모 소통 3종 → 학부모 후기 4개 → 누적 카운터 4종 → STEP1~4 아코디언 → 가격 앵커 → FAQ → 최종 CTA → 푸터.

선생님(/tutor)

다크 히어로(개인화 카피 + 만나보기 앵커) → 카운터 3종 → 학생 인터뷰 2컷(니즈↔강점 해시태그 매칭) → 이달의 선생님 캐러셀(해시태그 배지 3개·프로필·대학(전형)·이름(나이)·3줄 스토리·과목 칩·경력 배지·대학 워터마크·카드별 매칭 버튼) → 특별한 이유 3가지(Q&A 반박형) → 성적표 인증 12건 그리드 → 변경 보장 → 가격 앵커 → CTA.

수강후기(/review)

다크 히어로 → 성공사례 캐러셀(등급 화살표 + 해시태그) → 통계 밴드 → 합격통지서 실물 인증 3종 → 고민 카테고리 후기(#성적정체 #기초개념부족 #자신감하락 #목표부실) → CTA.

3. 디자인 언어

  • 보라 단일 브랜드 컬러, 다크 네이비 ↔ 라이트 섹션 교차.
  • 큰 국문 2줄 헤드라인, 강조어만 포인트 컬러.
  • 해시태그 칩을 정보+장식으로 광범위 사용.
  • 일러스트 대신 실물 사진·스캔 위주. 전 통계에 각주.
  • 상단 배너 + 하단 고정 CTA로 화면 상·하단 상시 점유.
