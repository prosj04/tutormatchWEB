카피 제안서 — 매칭 철학 기반 문구 복수안

섹션별 카피 후보(✅ 추천안)와 실제 사건 뉴스 활용 제안. 2026-07-06

> design-direction.md §1-1(매칭 철학)·§3(톤)을 기준으로 한 페이지별 카피 후보. ✅ = 추천안.

> 작성: 2026-07-06

0. 원칙

  • "어떤 아이에게 어떤 선생님이 오는가"(매칭 서사)를 성적 증거보다 앞세운다
  • 안전·검증(신원 확인, 수업 기록, 수락 절차)을 두 번째 축으로
  • 짧고 단정, 이모지 금지. 긴급성 연출은 허용

1. 홈

신뢰 바 (4항목 중 교체 1)

  • A안 ✅: 서울·분당 방문 수업 / 신원 검증 선생님만 배정 / 학생이 수락해야 시작 / 첫 수업 100% 환불
  • B안: 방문 수업 / 성향 맞춤 매칭 / 검증 선생님 / 첫 수업 환불
  • C안: 현행 유지(전담 매니저 포함)

문제 제기 부연

  • A안 ✅: "성적표가 아니라, 아이의 성향에 맞는 선생님이 필요합니다"
  • B안: "좋은 선생님과 맞는 선생님은 다릅니다"
  • C안: "1~2달을 잃고 나서야 안 맞는 걸 알게 됩니다"

매칭 철학 쇼케이스 (신규 섹션)

  • 헤드라인 A안 ✅: "어떤 아이에게, 어떤 선생님이 오는가"
  • 헤드라인 B안: "아이가 다르면, 선생님도 달라야 합니다"
  • 헤드라인 C안: "성향을 읽고, 사람을 맞춥니다"
  • 4쌍 카드(고정): 활발한 아이 — 잡아주는 카리스마 / 여린 아이 — 기다려주는 다정함 / 게으른 아이 — 본보기가 되는 성실함 / 롤모델이 필요한 아이 — 존경할 만한 인품

STEP2 (5단계 프로세스)

  • A안 ✅: "매니저 성향 진단 — 성적보다 먼저, 아이가 어떤 학생인지 듣습니다"
  • B안: "성향 인터뷰 — 공부 스타일·기질·목표를 정리합니다"

선생님 섹션 서브카피

  • A안 ✅: "아이의 공부 스타일을 듣고, 교육 철학이 맞는 선생님을 제안합니다"
  • B안: "지원자 절반이 탈락하는 검증을 통과한 선생님 중에서, 아이와 맞는 분만"
  • C안: "학벌은 기본입니다. 저희는 사람을 봅니다"

후기 섹션 제목

  • A안 ✅: "선생님이 바뀌자, 아이가 바뀌었습니다"
  • B안: "성적보다 습관이 먼저 바뀌었어요" (현행)
  • C안: "다른 집 아이들은 이렇게 달라졌습니다"

요금 섹션 서브

  • A안 ✅: "숨긴 가격이 없습니다. 상담에서 그대로 안내드립니다"
  • B안: "모든 플랜에 매니저 관리·리포트가 포함된 가격입니다"

최종 CTA 보상 문구

  • A안 ✅: "상담만 받아도 아이 성향 진단과 학습 방향을 정리해 드립니다"
  • B안: "상담에서 아이에게 맞는 선생님 유형까지 알려드립니다"

2. /tutors

검증 섹션 헤드라인

  • A안 ✅: "아무 선생님이나 소개하지 않습니다"
  • B안: "절반은 탈락합니다"
  • C안: "검증 없이 아이 앞에 세우지 않습니다"

인터뷰 매칭 섹션

  • A안 ✅: "이런 학생에게는, 이런 선생님"
  • B안: "학생의 니즈와 선생님의 강점이 만나는 지점"

3. /reviews

  • 히어로 서브 A안 ✅: "성적 상승보다 먼저, 아이와 맞는 선생님을 만난 이야기입니다"
  • 히어로 서브 B안: "선생님을 바꾸고 나서야 알게 된 것들"

4. 글로벌

  • 상담 모달 제목 A안 ✅: "우리 아이에게 맞는 선생님, 지금 찾기 시작합니다"
  • 상담 모달 제목 B안: "30초면 시작됩니다"

5. 실제 사건 뉴스 활용 제안 — "안전은 전제입니다"

확보된 사례 (언론 보도 기반, 요약·출처 표기 방식)

사례요지출처
과외교사 13세 학생 성추행 사건 (2025 발생, 2026-04 보도)20대 과외교사가 가르치던 초등학생을 성추행. 1심 징역 1년·집행유예 2년에 그쳐 학부모가 항소, 신상 유포 논란까지 확산서울신문 2026-04-14, 머니투데이 2026-04-15

시사점: 세 사건 모두 개인 간 직거래 과외에서 학부모가 선생님을 검증할 방법이 없었다는 공통점. "처벌도 가볍게 끝난다(집행유예)"는 최근 보도는 사전 검증의 필요성을 뒷받침한다. → 카피 앵글: "문제가 생긴 뒤에는 늦습니다. Concord는 시작 전에 검증합니다."

추가 확보 예정: 성범죄 전과자 교습 적발 사례, 무자격 교습 통계 (검색 가능 시 보강)

활용 수위 3안

  • 1안 (간접·제도 프레임): 사건명 없이 "신원 인증이 업계 의무가 된 이유가 있습니다" 수준으로만 언급 → 톤 가장 안전, 임팩트 약함
  • 2안 ✅ (출처 링크 카드): /tutors 검증 섹션 도입부에 소형 블록 — 헤드라인 "안전은 서비스가 아니라 전제입니다" + "과외 중개 플랫폼에서 신원 미확인으로 발생한 사건들이 보도된 바 있습니다" + 언론사·날짜 표기 링크 카드 1~2개 + "그래서 Concord는 신원·이력 검증을 통과한 선생님만, 모든 수업 기록과 함께 배정합니다" → 사실 기반, 공포 소구는 절제, 우리 검증 절차로 즉시 전환
  • 3안 (직접 헤드라인 인용): 기사 제목을 크게 인용 → 임팩트 최대지만 피해자 자극·브랜드 톤 훼손 위험. 비추천

표현 가이드 (법적·윤리 안전선)

  • 기사 본문 전재 금지 — 한 줄 요약 + 언론사·날짜 + 링크만
  • 피해자 신상·잔혹 묘사 금지, 사건을 조롱·과장하지 않음
  • 경쟁사(특정 앱) 이름을 우리 사이트에 직접 표기하지 않음 (명예훼손 리스크) — "일부 중개 플랫폼" 표현
  • 배치는 /tutors 검증 섹션 1곳 + 상담 모달 안심 문구 1줄이면 충분. 홈에는 넣지 않음(짜침 위험)
