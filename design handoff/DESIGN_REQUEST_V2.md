# 재요청 목록 v2 — 갱신 핸드오프 적용 후 남은 항목

작성: 2026-07-11 · 이전 요청(학생 웹·어드민·포털 보강·헤더·모바일 보강)은 **전부 반영 완료**.
아래는 적용 과정에서 드러난 잔여 항목. **[디자인]** = 디자이너 시안 필요, **[백엔드]** = 데이터/API 확장이 먼저 필요(디자인 무관), **[결정]** = 사용자 결정 필요.

## 1. [결정+디자인] 학생 웹 4화면 — 기능 보존형 전용 시안 필요
현재 시안(pg-dash·pg-consult·pg-checkout·pg-success)이 실제 기능보다 단순해서, 그대로 적용하면 기능이 삭제됩니다. 이번엔 **기존 화면 유지**(질문·알림·결제내역·계정 4개만 신 디자인 적용).
- `/dashboard` 학습 플래너: 달력·일일 계획 편집·이전 날짜 복사·만족도 체크인·선생님 교체 요청·매칭 수락 — 이 기능들을 포함한 시안 필요
- `/dashboard/consultation`: 방문 일정 3개 선택·상태 추적 포함
- `/checkout`·`/success`: Toss 자동결제 위젯·약관·CMS 문구 편집 지점 포함
→ 기능 목록 기준으로 재시안 요청 or 기능 축소 결정

## 2. [디자인] 헤더 로그인 상태 — 세부 3건
- 로딩 중 스켈레톤(현재 72×36 임의 pill) 규격
- 이름이 길 때 `.sess` 칩 말줄임/최대폭
- ADMIN 역할 칩 라벨·버튼 색 명세(시안엔 학생·학부모·선생님만)

## 3. [디자인] 어드민 — 세부 2건
- CMS 편집기 내부(드래그앤드롭 에디터 본체) — 현재 헤더만 신 디자인, 본체는 기존 UI 유지
- 학생/선생님 드로어 안의 "삭제" 확인 — 시안에 확인 모달 규격 없음(현재 브라우저 confirm)

## 4. [백엔드] 시안엔 있으나 데이터가 없어 미구현 (디자인 문제 아님)
- 리포트 **점수·과목별 막대(78→89)**: `monthlyReport`에 점수 필드 없음 (summary·weakTypes·detail만)
- 상담 완료 모달의 **"다음 단계"(매칭/보류/종결)** 선택 저장
- 수업 취소 **사유·보강 제안 시간** 저장 (현재 7일 뒤 자동 보강만)
- 리포트 **선생님/매니저 분리 코멘트** 필드
→ 원하시면 스키마+API 확장을 제가 진행한 뒤 UI 활성화

## 5. [디자인] 질문 화면 — 새 질문 작성 폼
질문 등록이 현재 플래너 안에서만 가능해, `/questions`의 작성 폼 대신 "플래너로 이동" CTA로 대체함. 질문 화면 자체 작성 폼을 원하면 시안+백엔드 흐름 확정 필요.
