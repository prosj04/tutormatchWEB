## 7. 회귀 스모크 (릴리스 전 5분)

1. 웹 로그인 → 학생 대시보드 또는 상담 페이지
2. 앱 로그인 → 홈 탭 데이터 로드
3. QnA 질문 1건 전송 (선생님 배정 계정)
4. 알림 벨 unread 표시
5. `npm run build` 통과
