작성: 2026-07-11 · 대상: 프론트엔드 디자이너
기준: 실제 코드의 **로그인 후 라우트 전체**를 `design handoff/` 시안(웹 포털·웹 학부모·모바일 4역할)과 1:1 대조. 비로그인(공개) 페이지는 제외.
기존 토큰 시스템(그린/블루 × 라이트/다크, `tokens-reference.css`)과 `portal.css`/`concord-app.css` 어휘를 그대로 확장해 주세요.

## A. 학생 웹 — 시안 전무 (8페이지)

| 라우트 | 화면 | 필수 기능 |
|---|---|---|
| `/dashboard` | 학생 홈 | 오늘 수업(선생님·과목·시각), 학습 진행 단계(상담→매칭→첫수업→수업중), 주간 숙제 요약·완료 체크, 최근 리포트 진입 |
| `/dashboard/account` | 계정 | 프로필 수정, 비밀번호 변경(현재+새 비번 8자+), **학부모 연결 코드/QR 발급·재발급**, 로그아웃, 탈퇴(확인 절차) |
| `/dashboard/consultation` | 상담 예약 | 방문 상담 신청(희망 시간대 3개), 접수 상태(대기→배정→방문확정→완료), 담당 매니저 표시 |
| `/questions` | 질문 | 질문 목록(해결/대기 상태), 질문 작성(사진 첨부), AI 즉답 → 해결됐어요/선생님께 질문 흐름, 토큰 잔량·소진 안내 |
| `/notifications` | 알림 센터 | 알림 목록(읽음/안읽음), 유형 아이콘(수업·리포트·결제·질문) |
| `/payments` | 결제 내역 | 결제·환불 이력 테이블, 현금영수증 링크, 구독 상태 |
| `/checkout` | 결제 | 플랜 요약(주1/주2·월 요금), 주문자 정보, 결제 수단, 약관 동의, 오류 상태 — 학생·학부모 공용 |
| `/success` | 결제 완료 | 완료 확인, 구독 정보, 다음 단계 안내(첫 수업 일정) |

## C. 웹 포털 — 시안이 정적 목업이라 세부를 임의 구현 (보강 요청)

| # | 화면·요소 | 현재 임의 구현 | 필요한 디자인 |
|---|---|---|---|
| C-1 | 학부모 리포트 **상세** (`/parent/reports`) | 행 클릭 토글로 요약·취약유형 노출 | 월 선택 → 본문(점수 변화·취약 유형 칩·코멘트) 레이아웃 |
| C-2 | 매니저 상담 **완료 모달**(노트)·**상담 리포트 모달** | 기본 모달 | 모달 규격 |
| C-3 | 매니저 모니터링 **드릴다운 드로어**(진도·미답변·케어로그 작성) | 우측 드로어 | 드로어 규격 |
| C-4 | 매니저 승인 화면 **수동 연결·비밀번호 재설정 폼** | 시안 정적 `.inp.filled` → select+input | 실입력·오류·성공 상태 |
| C-5 | 선생님 **첫 수업일 지정/수업 취소(보강 안내)** | 테이블 인라인 폼 | 인라인 vs 모달 확정 |
| C-6 | 선생님 진도·숙제 **분배 프리뷰·템플릿 저장/불러오기** | 시안 정적 값의 실동작판 | 값 변화·빈 상태·저장 피드백 |
| C-7 | 포털 공통 **상태 시스템** | 임의 | 로딩/빈/오류/성공·토스트·확인 다이얼로그, 사이드바 **로그아웃**(현재 user 칩 아래), 포털 <900px 반응형 |
| C-8 | 공개 헤더 **로그인 상태** | 기존 디자인 | 세션 칩·역할별 포털 버튼·로그아웃·모바일 드로어(신 시안엔 비로그인 헤더만) |

## D. 모바일 학생 앱 — 현존하지만 시안에 없는 화면 (4)

| 화면(라우트) | 상태 | 필요 판단 |
|---|---|---|
| `teacher/[id]` 선생님 상세 | 기존 구현 존재 — 핸드오프 문서는 "선생님 단독 화면 없음" 방침 | 유지 시 디자인 필요 / 폐기 시 홈·학습 내 표시로 대체 확정 |
| `consult/status` 상담 접수 상태 | 시안은 "접수 완료"만 — 별도 상태 추적 화면 존재 | 상태 타임라인(대기→배정→방문확정) 디자인 |
| `subscription` | 고아 화면(라우트 미등록, 하드코딩 가격) | 삭제 예정 — 디자인 불필요, 확인만 |
| `index` 스플래시/진입 게이트 | 토큰 확인 후 분기 | 스플래시(로고 타일) 규격 |

## E. 모바일 4역할 — 시안 커버 밖 예상 갭 (PART 3 정밀 대조 후 확정)

| # | 화면 | 필수 기능 |
|---|---|---|
| E-1 | 학생 앱 · 비밀번호 변경 | 현재+새 비번, 성공/오류 |
| E-2 | 선생님 앱 · 프로필 사진/서류 업로드 | 사진 선택, 이력서·증명서 업로드(진행률·삭제), 승인 대기 온보딩 |
| E-3 | 매니저 앱 · 선생님 승인 | 미승인 목록·승인/반려 ('도구' 화면 포함 여부 확인 필요) |
| E-4 | 학부모/선생님/매니저 앱 · 알림 센터 | 학생 앱 시안의 역할별 버전 |
| E-5 | 공통 상태 | 오류/빈/로딩, 풀투리프레시, 푸시 권한 요청 |
