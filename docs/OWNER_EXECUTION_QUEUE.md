> 2026-07-13 오너 지시: 집행 항목은 보류하고 확인 가능하게 누적 문서화.
> 각 항목: 무엇을/왜/예상 비용/집행 방법. 승인 시 해당 항목만 말하면 됨.

## 1. 도메인 구매
- **무엇**: 자체 도메인 (현재 tutormatch-web.vercel.app 서브도메인)
- **왜**: 브랜드 신뢰(C-4). 상담 전 학부모가 주소를 봄. 이메일 발신 도메인 정합에도 필요
- **비용**: 연 2~5만원 (.co.kr/.com), 결제 수단만 있으면 10분
- **방법**: 가비아/후이즈에서 구매 → 알려주면 Vercel 도메인 연결은 내가 처리
- **후보 확인 필요**: concord.co.kr 등 가용 여부 사전 조회 권장 (변리사 상표 조사와 순서 연동 — 상표 막히면 도메인도 재검토)

## 2. 배상책임보험
- **무엇**: 방문 수업 중 사고(대인·대물) 대비 영업배상책임보험
- **왜**: 방문형 사업 필수 안전판(C-6). 사고 1건이 파일럿 전체 신뢰 붕괴로 직결
- **비용**: 월 수만원대 (보장 범위 따라)
- **방법**: 손보사 3곳 견적 비교 (KB·삼성·현대 법인영업). 견적 질문지 필요하면 작성해줌

## 3. 법무 3콜
- **변호사 1콜**: 통신판매·환불규정·만14세 동의 + **학원법 지위**(다수 강사 조직 관리가 개인과외 신고 범위 넘는지 — 가장 급함) + 표시광고 3종
- **노무사 1콜**: 강사 위탁 vs 근로 분류 — 첫 계약서 문안 전 필수. 오분류 시 4대보험·퇴직금 소급
- **변리사 1콜**: "Concord/콩코드" 41류(교육) 선행상표 조사 — 선점당했으면 리브랜딩 문제
- **비용**: 자문료 건당 10~50만원대. 온라인 플랫폼(로톡 등)이 저렴
- **준비물**: 질문지 3종 내가 작성해둘 수 있음 — 승인만 하면 즉시

## 4. 정부지원 신청

- **왜**: 비희석 자본(D-19). 신청 자체는 무료
- **방법**: K-스타트업 공고 확인 → 신청서는 PSST 문서 기반으로 내가 각색 가능
- **시한 주의**: 공고별 마감 있음 — 승인 시 현재 열린 공고 조사부터 시작
