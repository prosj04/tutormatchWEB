> 조사 대상: `https://index.seoltab.com/` 및 하위 페이지(`/tutor`, `/review`, `/consult_request`, `/faq`)
> 작성일: 2026-07-06 · 목적: 설탭의 리드 획득·전환 구조를 분석하고 Concord 홈에 이식할 구체 계획 수립

## 0. 한 줄 요약

설탭은 **"둘러보게 하지 않고 상담을 남기게 하는"** 사이트다. 강사를 검색·비교하는 디렉터리가 아니라, **검증된 소수의 "이달의 선생님" 카드**만 보여주고 모든 버튼이 `consult_request`(무료 상담 리드폼) 한 곳으로 수렴한다. 전환의 무기는 **① 위험 제거(100% 환불·무료 교체), ② 숫자 신뢰(합격률·성적상승률·매칭수), ③ 마찰 최소화(가입·체험수업 없이 "단 5초" 상담)** 세 가지다.

### 1.2 CTA 인벤토리 — 모든 길은 상담으로

| CTA 문구 | 목적지 |
|----------|--------|
| 수업결제 | `seoltab.com/enrollment` (유일한 결제 동선) |
| **단 5초, 상담신청 남기기** | `/consult_request` |
| 빠른 상담으로 궁금증 해결하기 | `/consult_request` |
| 딱 맞는 선생님 추천받기 | `/consult_request` |
| **빠른 매칭받기**(선생님 카드) | `/consult_request?utm=...(강사식별)` |
| 개념인강 자세히 알아보기 | `/smart_content` |

→ 결제(`enrollment`) 한 곳을 제외한 **전 CTA가 상담 리드폼으로 수렴**. 선생님 카드의 "빠른 매칭받기"도 프로필이 아니라 **상담폼으로 직행**(UTM으로 어떤 선생님에서 왔는지만 추적).

### 1.3 선생님 페이지(`/tutor`) — ★우리가 이식할 핵심 패턴★

- **디렉터리가 아님.** 검색·지역/과목 필터 없음.
- **"이달의 선생님"** 큐레이션 카러셀 — 약 15명만 노출.
- 헤드라인: **"수업 후기와 경력으로 검증된 이달의 선생님"**
- 카드: 이름(예: 김지현T, 서정우T) + 검증 맥락. 상세 프로필 페이지로 안 넘어감.
- 각 카드 버튼 **"빠른 매칭받기" → `/consult_request`** (개별 프로필 X, 상담폼 O).
- 메시지: 올바른 매칭을 통해 "딱 맞는 학습 전략"을 찾는다는 프레이밍.

> **정확히 사용자가 원하는 구조.** 우리도 (1) 개별 강사 상세/디렉터리 제거, (2) 큐레이션 카드 일부만, (3) 카드 버튼 → 상담.

### 1.4 후기 페이지(`/review`)

- **카드 그리드**, 각 카드가 성적 향상 스토리.
- 카드 정보: **"4등급 → 1등급"** before/after, 학생명(예: 조연희 학생), 과목 태그(#국어#수학#영어), 합격대학(고려대·연세대), 학교유형(지방일반고), 장문 후기.
- 별점·사진·날짜는 **표시 안 함**(성적 변화가 별점을 대체).
- 집계: "설탭 수강생 2명 중 1명은 3개월 만에 성적 상승"(*2023.12~2024.01, 1,574명 중 867명).
- 고민 카테고리 태그: #성적정체 #기초개념부족 #자신감하락.
- CTA: "딱 맞는 선생님 추천받기" → 상담.
- 헤드라인: "설탭 수강생이 직접 경험한 성적 상승 후기를 만나보세요."

### 1.5 상담폼(`/consult_request`)

- JS 렌더라 정적 크롤로 필드 추출 불가(SPA). 관찰된 프레이밍: **"단 5초"**, **"무료"**, "결제 안 해도 컨설팅 무료".
- 유선 1:1 학습상담 + 학습진단서 기반 컨설팅. **가입/체험수업 요구 없음.**

### 1.6 FAQ(`/faq`)

- 카테고리: 신규 수강생 가이드 / 기기 가이드 / 학생 필독 / 학부모 필독.
- 반론방어 축: 체험수업 대신 100% 환불, 상담 절차, 효과, 습관형성, 할인.
- 지원 채널: 02-6205-0110(평일 10~19시), 채팅(평일/주말 10~19시).

## 2. 설탭의 고객획득 엔진 (전략 레이어)

1. **의사결정자 타겟팅 = 학부모.** 조직을 "학부모팀"으로 재편, 학부모 대상 학습 컨설팅. 입시 사교육 결정권자는 학생이 아니라 학부모라는 통찰.
2. **위험 제거로 마찰 붕괴.** 체험수업 없이 "첫 수업 후 100% 환불" + "무료 강사 교체". FOMO(긴급성)가 아니라 **의사결정 리스크 제거**가 주무기.
3. **숫자 신뢰 스택.** 53.3% 최종합격률 / 2명 중 1명 3개월 성적상승 / 만족도 97% / 9억+ 매칭 알고리즘 / 누적 만+ 지표.
4. **번들로 가격 민감도 완화.** "과외 한 과목=국영수 전과목 인강". 학원비 수준에 인강+교재+과외를 묶어 체감가치 확대 → "월 199,000원~" 앵커.
5. **강사를 상품이 아니라 신뢰 배지로.** 개별 비교를 막고 "전원 SKY·검증 통과"라는 **집단 신뢰**로 처리. 선택 피로 제거 + 매칭 알고리즘에 위임.
6. **매니저 중재 모델.** 학부모↔강사 직접 마찰 제거, "안심리뷰"로 커뮤니케이션 관리.
7. **콘텐츠/브랜드 유입.** 블로그(입시정보)·인스타(약 6.9천 팔로워)·유명인 광고("츄가 강추")로 상단 유입, 홈은 전환에 집중.

| 항목 | Concord(현재) | 설탭 | 개편 방향 |
|------|---------------|------|-----------|
| 강사 노출 | `/tutors` **디렉터리 + 과목필터 + 개별 상세페이지(`/tutors/[id]`)** | 큐레이션 15명, 상세 없음 | **디렉터리·상세 제거, 큐레이션 카드 일부** |

## 4. 흡수할 디자인/카피 (우리보다 나은 점)

**디자인 언어**
- 큰 숫자를 신뢰 앵커로: 스탯을 초대형 타이포로 단독 배치(“53.3%”, “2명 중 1명”).
- 섹션 리듬: 기능→통계→후기 3연속 반복으로 스크롤 설득.
- 보장 배지: 환불/교체를 아이콘+한 줄 배지로 반복 노출.
- STEP 1~4 넘버링으로 프로세스를 시각적으로 단순화.
- 학부모 후기를 별도 색 블록 카드로 분리.

**카피 공식(그대로 이식 가능)**
- 마찰 제거: **"당장 결정이 어렵다면? 무료 상담부터 가볍게"**, **"단 5초, 상담신청"**
- 위험 제거: **"첫 수업 후 불만족 시 100% 환불"**, **"마음에 안 들면 무료 교체 + 수업 추가"**
- 번들 가치: **"과외 한 과목만 들어도 전 과목 인강 제공"** (우리 버전으로 각색)
- 성과 증거: **"수강생 N명 중 1명은 3개월 만에 성적 상승"** (실데이터 산출 필요)
- 강사 집단신뢰: **"지원자 절반이 탈락하는 선발을 통과한 선생님만"**(이미 우리 카피에 유사 문구 존재)

## 5. Concord 개편 실행 계획 (구체)

### 5.1 선생님 페이지: 디렉터리 → "이달의 선생님" 큐레이션
- `TutorsListing.tsx`
  - 과목 필터(`FILTERS`, `chip-f`) **제거** 또는 숨김.
  - 전체 강사 map 대신 **큐레이션된 소수(예 6~9명)만** 노출. 소스 옵션:
    - (a) `getPublicTeachers()` 결과에서 상위 N만 슬라이스(간단), 또는
    - (b) CMS/DB에 `featured` 플래그 추가(정석). 초기엔 (a)로 빠르게.
  - `ConcordTutorCard`: `<Link href={/tutors/${id}}>` **제거**. 카드/버튼을 **상담 CTA(`useConsultationCta("tutors_featured")`)** 로 교체. 클라이언트 컴포넌트이므로 훅 사용 가능.
  - 헤드라인 교체: "이달의 검증 선생님" 톤. 서브카피에 검증/선발 강조.
  - 하단 `ConcordSubpageCta` 유지(이미 상담 유도).
- `src/app/tutors/[id]/page.tsx` **상세 라우트 제거**(또는 상담으로 리다이렉트). 내부 링크 정리 필요.
- 카드에 **"빠른 매칭받기"** 버튼 추가(설탭 문구 차용).

### 5.2 "매칭받기" → 상담 이동
- 이미 `useConsultationCta`가 존재. 카드 버튼 onClick에 연결만 하면 됨.
- 소스 태그를 강사별로 구분(`tutors_featured_${id}`)해 어느 카드가 전환에 기여하는지 GA4 추적(설탭의 UTM 방식 모사).

### 5.3 홈 카피/디자인 강화 (`LandingPageV2.tsx`)
- TEACHERS 섹션: 디렉터리 링크 대신 큐레이션 카드 + "빠른 매칭받기".
- PROMISE/보장: 100% 환불·무료교체 **배지**를 히어로 근처와 가격 근처에 반복.
- RESULTS: "N명 중 1명 3개월 성적상승"형 대형 스탯(실데이터 확보 후 수치 확정).
- REVIEWS: before/after 등급 변화 카드 포맷 도입(`/reviews`도 동일).

### 5.4 리드 마찰 축소
- 상담 신청을 **가입 없이** 남길 수 있는 초경량 폼 검토(현재는 비로그인 시 상담가입모달). 설탭 "단 5초" 벤치마크.
- (주의) 개인정보 수집 동의·스팸 방지 필요.

### 5.5 내비 정리 (`ConcordSiteHeader.tsx`)
- "강사진" 항목 라벨/링크 유지하되 목적지를 큐레이션 페이지로.
- (자료실 항목은 내부용이므로 출시 전 제거 대상 — 별도 이슈.)

- 강사 상세페이지 제거 시 **기존 SEO/북마크/내부링크** 깨짐 → 리다이렉트 처리.
- "100% 환불"은 실제 환불규정(`/refund`)과 문구 일치시켜야 함(법무 검토).
- 큐레이션 `featured` 소스를 코드 슬라이스로 시작하면 추후 CMS 플래그로 이관 권장.

## 7. 부록 — 이미지 슬롯 & 사진 메모 (생성 보류, 자리만 확보)

인물/성적 사진은 **아직 생성하지 않음.** 현재는 기존 기본 얼굴(`/images/teachers/default-*.png`)로 슬롯만 채워둔 상태. 아래는 실제 사진을 넣을 때의 방향 메모.

### 7.1 이달의 선생님 카드 포트레이트 (6장)
- 위치: `public/images/teachers/featured/tutor-1..6.png` (미생성). CMS 키: `tutors_featured / featured_N_photo`.
- 원하는 느낌:
  - 4:3 세로 상반신, 밝은 단색/스튜디오 배경, 자연광 톤. 카드 비율(`aspect-ratio:4/3`)에 맞춰 상단 정렬(`object-top`).
  - 20대 후반~30대 초반 한국인, 깔끔한 스마트캐주얼(셔츠/니트), 신뢰감 있는 옅은 미소. 과장된 보정 지양.
  - 남/녀 균형(현재 seed: 여4·남2 → 실제는 3:3 권장). 과목 특성과 무관하게 톤 통일(같은 배경·라이팅)로 카드 그리드 일관성 확보.
  - 배경색은 브랜드 톤(아이보리/그린 계열)과 충돌하지 않는 뉴트럴.
- 대안: 실제 강사 동의 사진 확보 시 그것으로 교체(가장 좋음). 없으면 Higgsfield `generate_image`로 6장 통일 스타일 생성.

### 7.2 성적 인증 / 후기 증거 이미지 (후기 페이지 개편 시)
- 설탭은 별점 대신 **"4등급→1등급" 등급 변화**를 카드에 노출. 우리도 후기 카드에 성적 변화 배지 + (선택) 성적표 인증 썸네일.
- 원하는 느낌:
  - 성적표/모의고사 성적표를 **개인정보 마스킹**(이름·수험번호 블러) 처리한 크롭 이미지. 실제 데이터 기반이어야 함(표시광고법 — 과장·허위 금지).
  - before/after 숫자는 이미지가 아니라 **텍스트 배지**로(접근성·다국어·CMS 편집 용이). 인증 이미지는 보조 신뢰 요소로만.
- 생성 vs 실데이터: 성적 인증은 **생성 금지 권장**(허위표시 리스크). 실제 수강생 동의 성적표만 사용. 목업이 필요하면 "예시" 워터마크 명시.

### 7.3 히어로/보장 배지 아이콘 (선택)
- 100% 환불·무료 교체·3단계 검증 배지는 현재 텍스트+체크(✓). 아이콘이 필요하면 라인 아이콘 세트로 통일(생성보다 아이콘 라이브러리 권장).
