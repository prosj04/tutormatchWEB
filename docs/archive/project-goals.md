# 프로젝트 목표 및 업무 흐름

> ⚠️ **정책 변경 고지 (2026-07-08)**: 아래 "학생은 배정된 선생님을 확인하고 수락 버튼으로 승인" 항목은 개정 이전 서술이다. 현행 규범(`CLAUDE.md`): 수락 버튼은 코드상 존재하나 **형식적 절차**이며 마케팅·UI에서 강조하지 않는다. 또한 2026-07-10부로 **학부모(PARENT)** 역할이 추가되어 역할은 학생·학부모·선생님·매니저·어드민 5종이다.

본 프로젝트는 튜터링 웹 애플리케이션으로, 학생, 선생님, 매니저(대표 매니저 포함)의 역할과 권한을 명확히 분배하고 효율적인 교육 과정을 지원하는 시스템 구축을 목표로 합니다.

## 핵심 목표

- 학생은 신청 또는 결제 흐름을 통해 서비스를 이용
  - 신청만 할 경우 매니저 배정 대기 상태
  - 결제 완료 시 자동으로 대표 매니저 배정
- 매니저는 배정받은 학생을 상담하여 선생님 배정 진행
  - 대면 상담 중 선생님 배정은 매니저 자율 운영
- 학생은 배정된 선생님을 확인하고 수락 버튼으로 승인
- 선생님은 첫 수업 날짜 설정 및 수업 시작
- 자동 숙제 분배 시스템 구축
  - 선생님이 주는 숙제를 일주일 또는 4일 단위로 자동 차등 분배
  - 주기적 반복 숙제는 간단 입력으로 자동 생성

## 헤르메스 업무 목표

- 대표 매니저 역할 권한 확장
- 승인 처리 및 자동 매니저 배정 기능 구현
- 선생님 배정과 학생 수락 플로우 구축
- 자동 숙제 분배 백엔드 및 UI 개발
- 보안과 역할 기반 인증 철저 적용
- 통합 테스트 및 문서화

## 배포된 작업

- 代表 매니저 권한 부여, 승인 API 개발 중
- 학생 및 선생님 등록, 인증 플로우 점검 완료
- 대시보드 접근 문제 및 승인 미비 상황 파악 및 개선 진행 중
