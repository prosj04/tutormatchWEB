## A. 학생 웹 4화면 — 기능 보존형 재시안 (최우선)

이전 학생 웹 시안(pg-dash·pg-consult·pg-checkout·pg-success)은 실제 기능보다 단순해 적용을 보류했습니다. 아래 기능 목록을 **전부 포함**해 다시 그려주세요.

### A-1. `/dashboard` 학습 플래너 (학생 홈)
- 월간 **달력**(날짜 선택, 계획 있는 날 표시)
- 선택 날짜의 **일일 학습 계획 목록**: 항목 추가/편집/삭제, 완료 체크
- **이전 날짜에서 복사** 액션
- 해당 날짜 **질문 등록**(사진 첨부) + 질문 목록
- **담당 선생님 카드**(이름·과목) + **선생님 교체 상담 요청** 버튼
- **매칭 수락 대기** 상태 배너(선생님 제안 수락/거절)
- **만족도 체크인** 응답 UI(주기적 팝업/카드)
- 사이드 내비: 내 질문 목록·결제/구독 내역 진입

### A-2. `/dashboard/consultation` 상담 예약
- 방문 상담 신청 폼: **희망 시간대 3개 선택**(날짜+시간)
- 신청 후 **상태 추적**: 대기 → 매니저 배정 → 방문 확정(확정 일시 표시) → 완료
- 담당 매니저 표시, 재신청 조건 안내

### A-3. `/checkout` 결제
- 플랜 요약(중등/고등 · 주1/주2 · 월 요금, 코드 확정가)
- **Toss 자동결제(빌링) 위젯 영역** — 카드 등록 UI가 들어갈 자리
- 주문자 정보, 약관 동의 체크
- 결제 실패/오류 상태(재시도 안내)
- CMS 문구 편집 지점(제목·안내문)이 있어 텍스트는 교체 가능해야 함

### A-4. `/success` 결제 완료
- 결제/구독 확정 정보(플랜·다음 결제일)
- 다음 단계 안내(첫 수업 일정은 선생님이 지정)
- 대시보드로 이동 CTA

## B. 헤더 (로그인 상태 보강)
- B-1. 세션 로딩 중 **스켈레톤** 규격 (현재 임시 72×36 pill)
- B-2. 이름이 길 때 세션 칩 **말줄임/최대폭**
- B-3. **ADMIN 역할** 칩 라벨·포털 버튼 색 명세 (현 시안엔 학생·학부모·선생님만)

## C. 어드민
- C-1. **CMS 편집기 본체** — 섹션 목록·문구 편집·이미지 슬롯·드래그 정렬·미리보기(iframe). 현재 헤더만 신 디자인
- C-2. 드로어 내 **삭제 확인 모달** 규격 (현재 브라우저 confirm)
- C-3. **대시보드 로딩/오류 상태** — 데이터 실패 시 오류 메시지+재시도 (현재 "불러오는 중" 무한 체류)

## D. 포털 공통 디테일
- D-1. **매칭 후보 0명 상태**: 사유 + 대안 행동(전체 선생님 보기 / 승인 대기 확인 / 학생 과목 수정 유도) 규격
- D-2. **disabled 버튼** 확정 규격 (현재 임시 opacity 50%)
- D-3. 네이티브 confirm 2곳 모달화: 상담 **"내가 배정" 확인**, 어드민 **삭제 확인** — `.scrim>.modal` 규격으로
- D-4. 질문 화면(`/questions`) **자체 질문 작성 폼** (현재는 "플래너로 이동" CTA — 작성 폼을 두려면 사진 첨부·과목 선택 포함)
