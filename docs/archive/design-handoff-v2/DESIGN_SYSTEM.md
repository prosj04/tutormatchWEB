# Concord 디자인 시스템 정의

개발 중 일관성을 유지하기 위한 **디자인 정의 문서**입니다. 토큰의 원본(Single Source of Truth)은 `design/tokens.css`이며, 이 문서는 그 토큰을 **언제·어떻게 쓰는지**를 규정합니다.

- 색·간격·타이포·반경·그림자 값은 반드시 `tokens.css`의 CSS 변수를 통해서만 사용합니다. **하드코딩 금지.**
- 테마는 두 축: `<html data-color="green|blue" data-theme="light|dark">` — 기본은 `green` + 라이트.

---

## 1. 브랜드 원칙
- **대상**: 학부모. 톤은 *신뢰·차분·전문성*. 과한 채도/네온/그라데이션 지양.
- **레이아웃**: 여백이 넉넉한 그리드, 강한 타이포 위계, 절제된 단색 액센트.
- **입체감**: 보더 라인이 아니라 **소프트 섀도우**(`--shadow-sm/md`)로 표현.
- **색 사용 공식**: *뉴트럴 베이스 + 단색 액센트*. 액센트는 면(버튼·CTA)과 강조 텍스트에만, 배경 대면적에는 쓰지 않는다(특히 다크).

---

## 2. 색 토큰 사용 규칙

| 토큰 | 용도 |
|---|---|
| `--bg` | 페이지 배경 |
| `--panel` | 카드·패널 표면 |
| `--panel-2` | 한 단계 들어간 표면(칩·아이콘 배경·미디어) |
| `--line` / `--line-2` | 구분선·테두리 (2는 더 진함, hover·강조) |
| `--fg` | 본문·제목 텍스트 |
| `--mut` / `--mut-2` | 보조 텍스트 / 더 흐린 캡션·placeholder |
| `--acc` + `--on-acc` | **면**(버튼·CTA 밴드·배지·표 헤더) 배경과 그 위 텍스트 |
| `--acc-text` | **본문 위** 강조 텍스트·체크마크·통계 강조·링크 |
| `--acc-rgb` | 틴트/글로우 (`rgba(var(--acc-rgb), …)`) |
| `--shadow-sm/md` | 카드 기본 / hover·강조 그림자 |

**핵심 규칙**
- 밝은 배경에서 `--acc`(면 색)를 텍스트에 직접 쓰면 안 읽힘 → 텍스트엔 항상 `--acc-text`.
- 다크에서 액센트는 **포인트로만**. 배경을 액센트 색으로 물들이지 않는다(그린 다크가 중립 차콜인 이유).
- 색 대비: 본문 텍스트 `--fg`/`--bg`는 WCAG AA(4.5:1) 이상 유지. 새 조합 추가 시 검증.

---

## 3. 타이포그래피

**서체**: Pretendard. `word-break:keep-all` 전역 적용(한글 어절 줄바꿈), 본문 `line-height:1.6`, 기본 자간 `-.01em`.

| 역할 | 토큰 / 크기 | weight | 자간 | 비고 |
|---|---|---|---|---|
| 디스플레이(히어로 H1) | `--fs-display` 46→124px | 800 | -.04em | lh 1.04 |
| 섹션 제목 H2 | `--fs-h2` 32→66px | 700 | -.03em | lh 1.08 |
| 통계·프로세스 번호 | `--fs-stat` 40→72px | 800 | -.03em | tabular-nums |
| 가격 | `--fs-price` 42px | 800 | -.03em | tabular-nums |
| 히어로 리드 | `--fs-lede` 18→25px | 400 | — | `--mut` |
| 섹션 설명 | `--fs-lead` 17→20px | 400 | — | `--mut` |
| 카드/행 제목 | `--fs-h3` 24px (카드 22 / 강사 18) | 700 | -.025em | |
| 본문·버튼 | `--fs-body` 16px | 400 / 700 | — | |
| 보조·캡션 | `--fs-sm/xs` 15/14px | 500/600 | — | `--mut` |
| Eyebrow 라벨 | `--fs-eyebrow` 13px | 700 | .22em | UPPERCASE, `--acc-text` |

**위계 원칙**: 800은 디스플레이 전용(히어로·통계·가격). 그 외 제목은 700. 굵기를 남발하지 말고 크기·색으로 위계를 만든다.

---

## 4. 간격 · 레이아웃
- **스페이싱 스케일**: 4px 베이스(`--space-1`=4 … `--space-18`=72). 임의값 대신 스케일 사용.
- **콘텐츠 폭**: `--wrap` 1280 → (≥1500) 1460 → (≥1900) 1640. 좌우 거터 `--gutter` 32 → 48.
- **섹션 패딩**: 상하 `--sec-pad` `clamp(92px,8.5vw,168px)`.
- **그리드 갭**: 카드 그리드 20px(≥1500: 26px).
- **반응형 분기**: `1900` / `1500`(폭·타이포 확장), `960`(4열→2열, 내비 간소화), `680`(1열, 통계 2열).
- 큰 화면에서 폭·타이포·여백이 *함께* 커지도록 `clamp()` 사용 — 좁은 칼럼이 방치되지 않게.

## 5. 반경 · 그림자
| 토큰 | 값 | 적용 |
|---|---|---|
| `--r-card` | 18px | 강사·학습관리·후기 카드, 비교표 |
| `--r-card-lg` | 22px | 요금제 카드 |
| `--r-wrap` | 20px | 비교표 래퍼·CTA 밴드 |
| `--r-control` | 12px | 테마 토글 등 사각 컨트롤 |
| `--r-pill` | 999px | 버튼·칩·배지·태그 |

그림자는 두 단계만: `--shadow-sm`(기본 표면) / `--shadow-md`(hover·추천 카드·CTA). 임의 그림자 추가 금지.

---

## 6. 모션
- 표준 이징 `--ease` = `cubic-bezier(.2,.7,.3,1)`.
- 인터랙션 트랜지션 .18s(버튼·hover) ~ .25s(카드 transform).
- 테마 전환 .4s(배경·텍스트 색).
- 스크롤 등장(`.reveal`) .8s, `prefers-reduced-motion`에서 비활성·즉시 표시.
- hover 상승은 `translateY(-2px ~ -6px)` + 그림자 `sm→md`. 장식용 무한 루프 금지(마키 제외, hover 시 일시정지).

---

## 7. 컴포넌트 명세(요약)
- **버튼**: `.btn`(pill, 15/26 패딩, 700). 변형 `.btn-acc`(면), `.btn-ghost`(패널+`--line-2` 보더), `.btn-sm`. hover: 색 변화 + `translateY(-2px)`.
- **헤더/내비**: sticky, 블러 배경 `--header-bg`. 스크롤 시 `--line` 보더 + 그림자. 우측에 라이트/다크 토글(☀/☾) + 주요 CTA.
- **히어로**: eyebrow → H1(키워드 `--acc-text`) → 리드 → CTA 2개 → 통계 3분할. 배경에 미세 그리드 + 액센트 라디얼.
- **마키/칩**: 성적 향상 사례. `.chip` 패널+`--shadow-sm`, 화살표 `--acc-text`. hover 시 정지.
- **강사 카드**: 미디어(placeholder, 실데이터는 사진) + 태그(면) + 이름/한줄/학력/항목. 검증 배지는 `--acc-soft` 톤(사용 시 `rgba(var(--acc-rgb),.10~.16)`).
- **학습관리 카드**: 아이콘(패널-2 배경) + 번호 + 제목 + 설명.
- **프로세스**: 큰 번호 + 제목/설명의 가로 행. hover 시 좌측 들여쓰기 + 번호 `--acc-text`.
- **요금제**: 2열. 추천 카드는 `--acc` 보더 + `--shadow-md` + 상단 배지. 체크 `--acc-text`.
- **비교표**: Concord 열 강조(헤더 `--acc` 면 + 흰 텍스트, 본문 셀 틴트). 다크 보정 규칙 필수.
- **후기**: 별점 `--acc-text` + 인용 + 출처.
- **CTA 밴드**: `--acc` 면 + `--on-acc` 텍스트. 버튼은 반전(배경=`--bg`/`--panel`, 텍스트=`--acc-text`).
- **푸터**: `--line` 상단 보더, 컬럼 링크, 메타·법적 표기.

---

## 8. 접근성 체크리스트
- 본문 대비 AA(4.5:1), 큰 텍스트 3:1 이상. 4조합 모두에서 확인.
- 히트 타깃 ≥ 44px(모바일).
- 포커스 가시성 유지(키보드 내비), 토글에 `aria-label`.
- `prefers-reduced-motion` 존중.
- 색만으로 정보 전달하지 않기(비교표 ✓/✗에 텍스트 병기).

---

## 9. 하지 말 것
- 토큰 밖 색·간격·그림자 하드코딩.
- 다크에서 액센트로 대면적 배경 칠하기.
- 밝은 배경 본문 텍스트에 `--acc`(면 색) 사용 → `--acc-text` 사용.
- 800 굵기 남발(디스플레이 외).
- 임의 반경/그림자 신설, 인라인 매직넘버.
