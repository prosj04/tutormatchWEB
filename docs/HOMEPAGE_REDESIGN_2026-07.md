# 홈페이지 개선안 — 설탭 티어다운 기반 (2026-07)

> 작성: 2026-07-04 · 근거: https://index.seoltab.com/ 전체 크롤(홈 1.25MB HTML 실측) + 자사 `LandingPageV2.tsx`(802줄)·`landing-v2.css` 코드 리뷰.
> 목표: **attractive, but not 저렴해 보이는** 홈. 설탭의 "설득 구조"는 가져오되, 설탭의 "시각 언어"(형광색·과밀 배너·반복 카루셀)는 가져오지 않는다.

---

## 1. 설탭 티어다운 — 무엇이 attractive하게 만드는가

### 1-1. 페이지 서사가 "학부모 불안 해소 순서"로 설계됨

| 순서 | 섹션 | 해소하는 불안 |
|---|---|---|
| 1 | 히어로: "중하위권 학생이 SKY에 합격해 선생님으로 거듭나는 곳" | 우리 애도 가능할까? (변화 서사) |
| 2 | 책임과외: 선별(최종합격률 53.3%) → 전문매칭 | 선생님 실력 믿을 수 있나 |
| 3 | **"그래도 선생님이 마음에 안 들면 어떡하죠?"** → 변경비용 지원·무료수업 추가·책임수업제도 | 매칭 실패 리스크 (질문형 헤드라인으로 정면 대응) |
| 4 | 매칭 후에도 계속되는 관리 (모니터링·피드백) | 결제 후 방치되지 않을까 |
| 5 | 내신대비 프로그램 (대비전략→맞춤수업→결과리뷰 3단계) | 체계가 있나 |
| 6 | 실증: "수강생 2명 중 1명은 3개월 만에 성적 상승 (1,574명 중 867명)" + 조사 시점 각주 | 진짜 효과 있나 |
| 7 | **학부모케어**: 안심리뷰 발송·맞춤 리포트·관리매니저 상담 + 학부모 실명 후기 4종 | 아이가 말 안 해줘도 알 수 있나 |
| 8 | 누적 통계 카운트업 → STEP 1~4 진행 순서 | 시작하면 어떻게 되나 |
| 9 | 가격 앵커 "이 모든 게 월 199,000원~" | 비싸지 않나 |
| 10 | FAQ("체험 수업은 없나요?" = 환불 제도 설명) → "상담신청, 5초면 충분합니다" | 마지막 망설임 |

### 1-2. 신뢰 장치 (우리가 배울 것)

- **구체 숫자 + 각주**: 53.3%, 1,574명 중 867명, "*2025년 1월~9월 기준 데이터". 반올림한 마케팅 숫자보다 어중간한 실측치가 더 믿긴다.
- **질문형 헤드라인**: "그래도 선생님이 마음에 안 들면 어떡하죠?" / "우리아이, 공부 잘 하고 있나요?" — 학부모 머릿속 문장을 그대로 꺼내 정면으로 답함.
- **마찰 제거 카피**: "단 5초, 상담신청 남기기". CTA마다 소요 시간을 명시.
- **플로팅 CTA 위 환불 배지**: "첫 수업 후 불만족시 100% 환불" 리본이 버튼 위에 상시 노출.
- **관리매니저를 독립 섹션으로**: 학부모 후기가 전부 "매니저" 언급 — 설탭 스스로 매니저가 핵심 전환 장치임을 알고 있음.

### 1-3. 가져오지 않을 것 (짜침 요인)

- 동일 후기 카루셀 6회 반복, 과밀한 형광 배너, "1등" 남발, 이모지·폭죽. 설탭은 물량형 매스 브랜드 언어 — 우리는 프리미엄 대면 서비스라 **여백·타이포·정직한 각주**가 맞는 언어다.

## 2. 자사 현황 진단

강점(유지): 에디토리얼 타이포 히어로, 절제된 컬러, CMS 연동, 비교표, 결과 마퀴, FAQ 아코디언.
약점(보완):

| # | 문제 | 설탭 대비 |
|---|---|---|
| W-1 | 매칭 실패 불안에 답하는 섹션이 없음 (환불·재매칭이 가격 부제·CTA 밴드에 흩어져 있음) | 설탭은 질문형 독립 섹션 |
| W-2 | 학습 관리 섹션이 건조한 카드 3장 — "학부모가 무엇을 받는지" 체감 불가 | 설탭은 리포트·매니저 상담을 구체 장면으로 |
| W-3 | 히어로가 텍스트만 — 제품(리포트·매칭·질답)이 보이지 않음 | 설탭은 수업 장면·UI 노출 |
| W-4 | CTA에 마찰 제거 장치 없음 (소요 시간·환불 배지) | "5초" + 환불 리본 |

## 3. 개선안 (구현 반영)

1. **히어로 우측 프루프 카드 스택** (W-3): 매칭 알림·수업 리포트·성적 변화 3장의 플로팅 UI 카드 — 사진 없이 제품을 보여주는 프리미엄 SaaS 문법. 모바일에서는 숨김.
2. **신규 "약속" 섹션** (W-1): 헤드라인 "선생님이 맞지 않으면 어떡하죠?" + 3약속 ① 추가 비용 없는 재매칭 ② 첫 수업 100% 환불 ③ 전담 매니저 중간 조율. Teachers 섹션 직후 배치(선별 → 그래도 불안 → 약속 순).
3. **학부모 케어 섹션 재설계** (W-2): 헤드라인을 질문형("아이가 말해주지 않아도, 아실 수 있습니다")으로, 좌측 기존 CMS 3항목 + 우측 카톡형 수업 리포트 목업 카드. 기존 CMS 키(management.item1~3) 그대로 사용.
4. **플로팅 CTA 환불 배지** (W-4): 모바일 하단 고정 버튼 위 "첫 수업 100% 환불 · 상담 신청 30초" 마이크로 카피.
5. **CTA 마찰 제거 카피**: 히어로·CTA 밴드 버튼 주변에 "30초면 충분합니다" 계열 문구.

섹션 순서(변경 후): Hero(+프루프 카드) → Results → Teachers(선별) → **약속(신규)** → 학부모 케어(재설계) → Process → Pricing → Compare → Reviews → FAQ → CTA 밴드.

## 3.5 2차 개선 (서브페이지 순회 + 사용자 피드백 반영, 같은 날)

서브페이지(/tutor, /review) 추가 티어다운에서 얻은 것: ① Q&A형 불안 대응("대학생이라고 무책임하지 않나요?" → 답 + 66% 각주) ② 후기를 고민 유형(#성적 정체·#자신감·#기초 부족)으로 분류 ③ 성적표 "인증" 신뢰 장치 ④ 가격 앵커 반복.

반영 (사용자 확정 방향: 목업 확대 · 이미지 축소 · 짜침 배제):

6. **선생님 카드 컴팩트화** — 풀폭 4/3 이미지 → 56px 원형 아바타 + 과목 칩. 이미지 면적 최소화(사용자 피드백: "이미지 부담스럽다").
7. **케어 목업 스택 확장** — 수업 리포트 카드 아래 **질문·답변 채팅 목업** 추가 (학생 밤 11:24 질문 → 선생님 아침 7:40 답변). 실제 QnA 기능 기반.
8. **Process 섹션 2단화** — 좌측 5단계, 우측 **진행 알림 목업 스택** (상담 접수 → 방문 상담 확정 → 선생님 배정 + "수락하고 첫 수업 잡기" 버튼 목업). 학생 수락 플로우(제품 노스스타 §6)를 그대로 시각화.

미반영 보류: 후기 고민 태그 분류(CMS 후기 스키마에 태그 필드 없음 — 후기 실데이터 쌓인 뒤 /reviews 페이지에서 검토), 성적표 인증 각주(파일럿 전이라 실측치 없음 — 정직 원칙).

## 4. 하지 않은 것 (의도적)

- 누적 통계 카운트업 애니메이션 — 파일럿 전이라 부풀릴 숫자가 없음. 실측치 확보 후(트래션 리포트) 추가.
- 후기 카루셀 다중 반복 — 짜침 요인으로 판정.
- "1등" 류 최상급 표현 — 표시광고법 리스크(MARKETING_PLAN §9)와 브랜드 톤 모두에 어긋남.
