한눈에 보는 Concord

면접·검증된 강사와 전담 매니저가 대면 1:1 과외를 매칭·관리하는 프리미엄 에듀테크. 아이디어 단계가 아니라 웹 4역할 포털·결제·AI 질답·학습관리가 모두 작동하는 완성된 소프트웨어입니다.

사용자 역할

4역할 포털

학생/학부모 · 강사 · 매니저(+최고매니저) · 최고관리자

상담→수락→수업

상담 신청 → 매니저 배정 → 대면 상담 → 강사 매칭 → 학생 수락 → 첫 수업 → 진행관리

후기 — 제품 차별점이 곧 사회적 증거

public/desktop/reviews.png

성적 수치가 아니라 습관·태도 변화 중심의 후기 카드. 제품의 차별점이 그대로 후기 언어가 됩니다.

후기 = 기능 증거
  • "매니저님이 직접 상담…" → 매니저 매칭
  • "밤에 올리면 AI가 바로 답…" → 질답
  • "안 맞아서 무료 재매칭…" → 수락 구조

각 후기가 특정 기능(2.2·2.5·4.1)의 실체를 지목 — 마케팅 카피와 제품이 1:1로 연결됩니다.

PART 2

학생 여정
상담부터 수업 진행까지

제품 북극성은 "화면 너머가 아니라 옆자리에서". 학생 대시보드는 학습 단계(Journey Stage)에 따라 다른 화면을 보여주며, 각 단계는 실제 DB 상태에서 자동 산출됩니다.

STEP 1상담 대기상담 신청 접수
STEP 2매니저 배정최고매니저 자동 배정
STEP 3매칭 진행대면 상담 완료
STEP 4강사 수락 대기학생 수락 버튼
STEP 5첫 수업 대기강사 일정 설정
STEP 6수업 진행ACTIVE 대시보드

⑤ AI + 강사 질답(Q&A) — 두 번째 차별점

student/desktop/questions.png

실제 스레드 예시

  • 강사 보강 — "y=|x| 예를 꼭 기억" → 해결됨

사업적 의미 — "밤에 질문해도 방치 안 됨"의 실체이자, AI 토큰 = 원가 통제 가능한 부가가치.
