# 매니저 운영 가이드

## 1. 구독 일시정지

### 허용 기준
- **최대 1개월(30일)**: 한 번의 일시정지는 최대 35일까지 가능 (시스템 제한)
- **연 2회 권장**: 과도한 일시정지는 학생 학습 지속성에 영향
- **허용 사유**: 시험 준비, 해외 여행, 건강 사유 등 정당한 사유

### 절차
1. **학생 요청 접수**: 학생이 매니저에게 "구독 일시정지를 원합니다" 문의
   - 학생 자신은 구독을 자가 관리할 수 없으며, 매니저 포탈을 통해서만 처리됨
2. **사유 확인**: 상담 또는 이메일을 통해 일시정지 사유 및 기간 확인
3. **일시정지 처리**
   - 매니저 포탈에서 구독 일시정지 기능 클릭
   - 일시정지 재개 예정일 입력 (ISO 형식, 예: 2025-01-15)
   - API: `POST /api/manager/subscriptions/[id]/pause` → body: `{ action: "PAUSE", until: "2025-01-15", reason?: "시험 준비" }`
4. **재개 처리**: 만료일이 되면 또는 학생이 조기 재개를 요청하면
   - API: `POST /api/manager/subscriptions/[id]/pause` → body: `{ action: "RESUME" }`
   - **중요**: 일시정지 기간만큼 만료일이 자동 연장됨 (자신이 수동 연장 불필요)

### 기록 원칙
- 일시정지 사유를 케어 로그에 기록 (예: "시험 3주 일정, 2025-01-15까지 일시정지")
- 재개 시에도 기록하여 추후 학생 관리 내역 추적 가능하게 함

## 2. 상담 노쇼 대응

### 절차
1. **자동 리마인더 발송**: 시스템이 상담 24시간 전 학생/보호자에게 리마인더 발송
2. **노쇼 발생**:
   - 상담 시간 경과 후 상담이 미완료면 자동으로 '노쇼' 상태 전환
   - 매니저는 알림을 받고 학생에게 재연락
3. **2회 노쇼 규칙**:
   - 동일 학생 2회 노쇼 발생 → **치프 매니저에게 보고**
   - 학생 학습 태도 평가 및 계약 조건 재검토 필요
4. **재상담 일정 조율**: 노쇼 사유 확인 후 새로운 상담 일정 제안

---

## 3. 선생 교체 요청 처리

### 절차
1. **요청 접수**: 학생이 "선생님 교체 요청" 문의
2. **알림 전송**: 학생이 요청한 이유를 정리하여 기록
3. **3일 내 학생 통화**: 
   - 교체 이유를 상세히 확인 (학습 방식, 상호 호환성 등)
   - 현 선생님과의 개선 여지 검토
4. **재매칭 처리**:
   - 승인 결정 시 새로운 선생님 선택
   - 선생님 변경 사실을 학생에게 통보
   - 신규 선생님의 첫 수업 일정 조율

---

## 4. 선생 귀책 취소

### 절차
1. **취소 원인 파악**: 선생님 부재, 준비 부족 등 선생님 귀책으로 수업 취소됨
2. **보강 수업 자동 생성 확인**: 
   - 시스템이 자동으로 보강 수업 레코드 생성
   - 매니저는 생성 상태를 확인
3. **학생 안내**: 
   - 학생에게 보강 수업 일정 안내
   - 학습 계획 영향도 확인 및 조정

---

## 5. 케어 로그 작성

### 작성 기준
- **주기**: 학생당 **주 1회 이상** 권장 (최소 월 4회)
- **내용**: 
  - 상담, 모니터링, 학습 진행 상황 점검
  - 학생 관심사 및 우려 사항
  - 선생님과의 소통 내용 요약

### 공개 범위 판단
- **학생 공개**: 학생이 이해하면 좋을 긍정적/객관적 피드백
  - 예: "수학 개념 이해도 개선 중"
- **매니저/치프만 열람**: 민감한 개인 정보나 조직 판단 내용
  - 예: "가정 사정으로 학습 집중도 저하 중, 추가 지원 계획"

---

## 참고 사항

- 모든 처리는 해당 학생의 담당 매니저가 수행
- CHIEF_MANAGER는 모든 학생 구독 관리 가능
- 학생은 매니저에게 "매니저에게 문의" 버튼을 통해 요청
- 시스템 장애나 정책 변경 시 치프 매니저에게 보고
