## A. 신규 발굴 32건

### A-1. 지역 확장 (EI-1 ~ EI-4)

**EI-1 / 동별 진입 스코어카드 v1**
- 무엇·왜·어떻게: 신규 동 진입 판정 도구가 없다 — D-25(대기자 선확보)·D-26(서울 검증)은 원칙만 있다. 5지표 스코어카드 1장을 만든다: ① 중·고 재학생 수(학교알리미·교육지원청 공시) ② 입주 5년 내 신축 대단지 세대수 ③ 기존 학원가 밀도(낮을수록 "방문 큐레이션 공백" — §7 I-1 교체 논거의 도구화) ④ 강사 이동시간 대중교통 30분 상한 ⑤ 해당 동 대기자·상담신청 실적(C-38 시트). 5지표 중 4 충족 시에만 진입 브리핑 상정. 확장 실패의 최빈 원인은 수요가 아니라 공급(강사 이동) — 지표 ④를 하드 컷으로 둔다.
- 발동: 문서 작성 P-수칙 / 판정 사용 B
- 증거: E2(D-25·D-26·SYN-9, §7 I-1 논거 교체 기록) + E4
- 오너 시간: 승인 10분 (작성은 AI)
- 선행: C-13 폼 구·동 필드(마스터 §3-5), D-1 이동시간 기록 습관

**EI-2 / 2호 지역 = 강사 이동 축(신분당선) — 수지·광교 우선, 판교·분당 후순위**
- 무엇·왜·어떻게: 방문과외의 한계비용은 강사 이동시간이다. 강사 풀은 서울 주요대 재학생 — 저녁 시간에 환승 1회 내로 닿는 축이 서비스 가능 반경을 정의한다. 신분당선 축(수지·광교)은 강남·사당 경유로 서울권 강사가 도달 가능하고, 신도시 특성상 방문 큐레이션 공백이 크다. 판교·분당은 평촌·대치 접근성 높은 학원 밀도로 후순위. MH-1이 "수지·광교" 표기 심화를 이미 언급했으나 그것은 표기 제안 — 본안은 진입 순서 결정이다. EI-1 스코어카드로 최종 판정.
- 발동: B~C (EI-1 통과 시)
- 증거: E2(MH-1) + E4(지리 추론 — 추정 표기)
- 오너 시간: 결정 30분
- 선행: EI-1, 동탄 cell 손익 확정(D-15)

**EI-3 / 서울 첫 진입 구 = 신축 대단지 "공백 축" (마곡·고덕·위례류)**
- 무엇·왜·어떻게: 서울 진입 시 대치·목동 정면 승부를 피한다 — §7에서 I-1("강남보다 밀도 우월" 서사)이 기각되고 "신도시 방문 큐레이션 공백"으로 논거 교체된 것의 서울판 적용. 마곡·고덕·위례처럼 입주 10년 내 대단지가 밀집하고 학원가가 미성숙한 권역을 첫 서울 cell 후보로 상정하고, EI-1 스코어카드에 "입주 연차 5년 내 세대수" 가중치를 둔다. 동탄에서 검증된 플레이북(신도시·대단지·맘카페 권역)을 그대로 이식할 수 있는 지형을 고르는 것이 핵심.
- 발동: C (Gate3~4, D-26과 동시 판정)
- 증거: E2(§7 I-1 교체 기록·D-26) + E4
- 오너 시간: 결정 30분
- 선행: EI-1, 동탄 플레이북 문서화(D-15·D-24)

**EI-4 / 채용 퍼널 = 지역 확장 센서 (지원서 거주·이동권역 필드)**
- 무엇·왜·어떻게: 수요 센서(C-38 대기자 지도)는 있는데 공급 센서가 없다. 강사 지원서에 거주 동 + 이동 가능 권역(복수 선택) 필드를 추가하고 어드민에서 분포를 집계한다. 다음 지역 결정 시 "그 동네에 보낼 수 있는 강사가 이미 지원해 있는가"를 실측으로 답한다. M-38 공고 게시 전에 반영하면 데이터가 첫날부터 쌓인다. 코드 소작업(폼 필드+집계 뷰 0.5일).
- 발동: P(필드 추가) / 활용 B
- 증거: E1(강사 온보딩 라우트 실존 — R2b 검증 범위) + E2(M-38·C-38)
- 오너 시간: 0
- 선행: M-38 공고 게시 전 반영이 최적

### A-2. 공급 스케일 (EI-5 ~ EI-12)

**EI-5 / 대학별 채용 파이프라인 (에타·알바몬의 다음 단계)**
- 무엇·왜·어떻게: M-38(에타·알바몬 공고)은 소진성 채널이다. 대학 단위 반복 구조로 승격한다: ① 서울 주요대 커리어센터 공고(무료) ② 사범대·교직이수·교육대학원 게시판 ③ 교육봉사·과외 동아리 제휴 ④ 3월·9월 개강 2주 전 게시 리듬 고정 ⑤ 12월 합격 발표 후 예비 신입생은 3월 입학 시점에 풀 편입. 소구는 시급 경쟁이 아니라 안정성 — 숨고 기준 수학 과외 평균이 시간당 45,000원으로 형성돼 있어([숨고 수학 과외 비용](https://soomgo.com/prices/%EC%88%98%ED%95%99)), Concord 정산 30,000~40,000원은 시세 하단이다. 따라서 "월 실효 수입 안정성+행정대행"(C-15 카탈로그) 소구를 공고 문안의 본문으로 삼아야 한다.
- 발동: A (M-38 1차 성과 확인 후)
- 증거: E3(숨고 시세) + E2(M-38·C-15·20-마케팅 §0-2 공급 선행 원칙)
- 오너 시간: 공고 문안 승인 20분, 동아리 제휴 회당 1h
- 선행: M-38 개시, C-7 시급 실조사(§B 병합 참조)

**EI-6 / 강사 추천 채용 보상 제도**
- 무엇·왜·어떻게: 재직 강사가 동료를 추천해 첫 수업 개시에 도달하면 추천 보상을 지급한다(예: 10만원 상당 — 금액은 오너 전권). 할인 금지 제약은 소비자 가격에 관한 것 — 채용 측 보상은 저촉 없음. 추천 채용은 공고 대비 CAC가 낮고 품질 사전 필터 효과가 있다. M-24(추천 고지)는 고지 의무만 다루는 별개 항목 — 보상 제도 자체는 신규 실행체.
- 발동: A (재직 강사 3명 이상)
- 증거: E2(M-24와의 구분) + E4
- 오너 시간: 보상액 결정 5분 — **오너 결정 필요**
- 선행: 첫 정산 사이클 1회 완주(지급 신뢰 확보 후)

**EI-7 / 강사 채용 전용 랜딩 /recruit (별 라우트 — 홈 동결 무관)**
- 무엇·왜·어떻게: MH-3(학교명 SEO 별 라우트)과 동일한 방식으로 홈 코드 비접촉 별 라우트를 만든다. 내용: D-10 실질시급·직거래 손실 표, C-15 행정대행 가치, C-17 경력증명, 선별 절차 사실 서술(카피 헌법 준수). 대학별 UTM으로 EI-5 파이프라인의 착지면이 된다. 현재 강사 채용은 공고 텍스트뿐 — 착지면 없이 파이프라인을 늘리면 전환이 샌다.
- 발동: A
- 증거: E2(MH-3 선례·D-10·C-15·C-17)
- 오너 시간: 카피 검수 15분 (코드 0.5일은 AI)
- 선행: EI-5와 동시가 최적

**EI-8 / BYOS — 강사 지참 학생 편입 트랙**
- 무엇·왜·어떻게: 신규 강사가 기존 개인 과외생을 Concord 관리 체계로 편입시키는 경로를 공식화한다. 강사 유인 = 시급 프리셋 상향 수동 지정(32,000/34,000원 — **기구현 레버**, 커밋 01c21f4) + 행정대행 + 경력증명. 가정 유인 = 매니저 관리·리포트·환불 보증. CAC 0에 가까운 수요 확보와 강사 리텐션을 동시에 얻는다 — 직거래 이탈(D-9)의 역방향 활용. 리스크: 기존 직거래가가 확정가보다 낮으면 가정이 인상으로 인식 — 전환 강제 금지, 낮은 전환률 전제(추정).
- 발동: A
- 증거: E1(차등시급 프리셋 구현 완료) + E2(D-9·C-15) + E4(전환률)
- 오너 시간: 트랙 승인 10분, 건당 시급 지정 5분
- 선행: D-12 노무사 콜(계약 문안), C-15 카탈로그

**EI-9 / 고등(수능) 트랙 강사 요건 분리**
- 무엇·왜·어떻게: 고등 요금제(43·58·78·112만)는 실존 상품인데 공급 요건 정의가 없다. 채용 공고·면접 체크리스트를 중등 내신 트랙 / 고등 수능 트랙으로 이원화하고, 고등 트랙은 수능 실전 성적 증빙을 요구하며 시급 프리셋 34,000/40,000원을 활용한다. M-28(고3, 9월 모평 발동)이 기각 철회로 살아난 만큼, 공급 선행 원칙(공급은 수요 파도보다 2~6주 먼저)에 따라 여름 안에 요건표가 있어야 한다.
- 발동: A (M-28 발동 6주 전)
- 증거: E1(프리셋) + E2(M-28 재심-2·20-마케팅 §0-2)
- 오너 시간: 요건표 승인 15분
- 선행: M-38 개시

**EI-10 / 신규 지역 개척 수당**
- 무엇·왜·어떻게: EI-1 통과 지역의 첫 배정 강사에게 한시적으로 교통 실비 + 시급 프리셋 1단 상향(수동 지정 — 기구현)을 적용하고, 해당 지역 활성 3가정 도달 시 표준으로 환원한다. 신규 지역 초기엔 밀도 0이라 강사 이동 부담이 최대 — 확장 콜드스타트의 공급 측 해소 장치. 소비자 가격 불변(강사 정산 측 조정만).
- 발동: B~C
- 증거: E1(프리셋 레버) + E4
- 오너 시간: 지역당 결정 10분

**EI-11 / 단일 강사 의존 리스크 맵**
- 무엇·왜·어떻게: 동별 활성 가정 수 대비 커버 가능 강사 수를 스프레드시트 1장으로 주 1회 갱신 — 강사 1명 이탈 시 재배정 불가에 빠지는 가정 수를 상시 가시화한다. C-16(무마찰 재배정 프로토콜)의 선행 경보이자 C-18(수기 잔고 ×1.3)의 지역 해상도판. 확장할수록 이 맵의 빨간 칸이 진입 중단 신호가 된다.
- 발동: A
- 증거: E2(C-16·C-18)
- 오너 시간: 0 (매니저 루틴 5분/주)

**EI-12 / 면접 2단계화 — "대표 직접 면접" 클레임 보존형**
- 무엇·왜·어떻게: 강사 20명+ 구간에서 오너 전원 대면 면접은 채용 병목이자 키맨 리스크다. 서류·수업 시연·신원 확인은 치프 매니저 1차로, 오너는 최종 인성·판단 15분만 담당하는 2단계 설계를 지금 SOP로 문서화해 둔다. 클레임 "대표가 전원 직접 면접"은 최종 단계가 오너인 한 사실로 유지된다 — 다만 클레임 문안과 절차의 정합은 오너 판단 사안. C-49(승인 권한 위임)는 시스템 권한, 본안은 면접 절차 — 실행체 상이.
- 발동: 설계 P-수칙 / 시행 B
- 증거: E2(SYN-10·C-49·BUSINESS_DIRECTION §2 "전원 직접 면접") + E4
- 오너 시간: SOP 승인 15분 — **오너 결정 필요(클레임 문안 유지 여부)**
- 선행: 2호 매니저 또는 치프 승격자 존재

### A-3. 셀 복제·조직 (EI-13 ~ EI-14, EI-28 ~ EI-30)

### A-7. 채널·실험·자본·문서 (EI-24 ~ EI-27, EI-31 ~ EI-32)

**EI-24 / 세그먼트 진입 최소 실험 킷 (표준 규격 1장)**
- 무엇·왜·어떻게: 신규 세그먼트·신규 동 진입 논쟁을 의견이 아니라 규격화된 소액 실측으로 치환한다. 공통 규격: 별 라우트 랜딩(MH-3 방식·홈 비접촉) + UTM + 상담 폼, 광고 5만원 상한(M-34 당근 테스트 선례), 2주, 컷라인 = 리드 3건. 통과 시에만 오너 브리핑 상정. 이후 모든 확장 세그먼트 안(EI-16 예비중1, N수 Gate3 등)의 공통 선행 도구가 된다.

## C. 검토 후 제외 (발굴 과정 기록 — 신규 기각 제안 아님)

3. **방학 캠프·부트캠프류** — §7 기각 명부(I-26·S-30) 준수, 재론하지 않음. 시즌 수요는 C-14+M-27(상위플랜 전환)로 처리됨을 확인.
4. **앱 내 후기·평점 기반 확장 장치** — 헌법 금지(법률 스탠스 §8·큐레이션 세계관). 검토 자체 종료.
