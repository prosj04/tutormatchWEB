**재심-2. M-28 고3 세그먼트 — "확장기 기각" → A 재배치(부분 뒤집음). N수만 Gate3 유지.**
M-verdict는 "N수·고3 타깃팅은 파일럿 믹스(중등 중심, 객단가 65만) 밖 = I-19 시니어 기각 논리와 동일"로 세그먼트 부분을 기각했다. 두 가지 논거 결함:

또한 이 기각은 **X-22("직전 시험 직후 복기 상담 = 최저 CAC 창")·D-32("N수는 법무 단순 = 확장 용이")와 동일 원리를 다른 문서에서는 채택**한 것과 모순된다. 정리: **타이밍 원리(모평 직후) A 생존은 유지, 고3 재학생 세그먼트는 기각 철회 → A(9월), N수생만 §6 확장2 Gate3 유지**(D-32 법무 근거 정합).

**재심-3. P-38 매칭 후보 AI 브리핑 — 기각 논거 교체 + "기각" → "확장기 승계". [재분류]**
P-verdict 기각 사유 두 축 중 "후보 비교 UX 누출=세계관 붕괴 최대리스크"는 **기준 오적용**이다. 세계관 헌법(§11 비교·평점 금지)은 **학부모·학생 노출면** 기준이며, 같은 verdict가 P-31(TutorReview 내부신호)을 "세계관 우회 정확(학생 비노출)"으로 통과시켰고 C-19(수기 코호트)·D-4(매니저 판단 보조 체크리스트)도 같은 기준으로 생존했다. 매니저 내부 도구인 P-38에만 세계관 붕괴를 적용한 것은 **P-31 판정과의 내부 모순**. 유효한 기각 근거는 "강사 3~4명·활성 5명엔 모수 무의미(기회비용)"뿐이다. 처방: C-46·C-49 방식대로 **폐기가 아닌 확장기 승계** — D-4 큐레이션 규칙표→D-27 검증셋→NX-18 강사도구 라인에 수렴, 발동은 B(강사 풀 규모 후). 논거가 교정돼야 확장기에 재론할 때 "세계관 위반"이라는 잘못된 선례가 남지 않는다.

**재심-4. 수업확인 코드 정합 — P-verdict "전제 오류·중 개발" 판정 뒤집음, V-verdict 채택. [verdict 간 모순 해소]**
P-verdict(§0)는 "run-alert-checks는 여전히 D+7 자동 COMPLETED 수행 = 코드는 아직 자동완료, P-8/42/43 전제 오류"로 판정. V-verdict는 "구 자동완료(12h·60min) 폐지됨, 확인요청+D+1/D+3 리마인더 구현됨, D+7 fallback만 상존 — 중 개발 과대"로 판정. **코드 재독 결과 V가 정확**: `src/lib/run-alert-checks.ts:391~398` 주석·구현 모두 "자동 완료(구 12h·60min 버퍼)를 폐지하고 … 확인 요청 … D+1·D+3 리마인더 … D+7 & 여전히 SCHEDULED → 자동 COMPLETED + 사유 기록 + 3자 알림". 제도 골격은 기구현이고, 남은 것은 **D+7 fallback 정책(자동완료 유지 / MEMORY대로 비과실 이월 / 무한대기) 오너 결정 1건 + 소 수정**. P-8·P-42·P-43의 "코드 정합 선행(중)" 조건은 "오너 결정 1건+소 수정(0.5일)"로 격하한다. ※MEMORY 확정("비과실=마지막 수업으로 이월")과 fallback 자동 COMPLETED(정산 포함으로 흐름)는 **현재 어긋나 있음** — §2 재배치-2 참조.

**재심-5. M-24 강사 유유상종 추천 — A → P 후반. [시기 뒤집음]**
조건 "강사 3명+ 확보 후(A)"는 성립 시점을 오산했다. C-8(창립강사 3~4명 확보)은 **P 항목**이며 M-38(채용 최선행)은 verdict 자신이 실행 2위로 올렸다. 즉 조건은 A가 아니라 **P 내에서 충족**된다. 창립강사 온보딩 자료(D-10 손익 카탈로그)에 "추천 합격+개시 시 10만" 한 줄을 넣는 것은 비용 0 — 공급 CAC를 낮추는 가장 빠른 레버를 한 구간 늦출 이유가 없다. **P(온보딩 시 고지)→A(발동 집계)**로 재배치.

### 1-B. 논거 보강 (기각·조건부 유지하되 근거 교정, 4건)

**재심-6. V-5 슬롯 축약 — 기각 유지, 논거 교체.**
기각 사유 "선택지 과다=결정 마비는 증거 0인 가설"은 **사실관계가 약하다** — 선택 과부하는 Iyengar & Lepper(2000) 잼 실험 이래 확립된 연구 주제로 "증거 0"이 아니다. 단 Scheibehenne 외(2010) 메타분석은 평균 효과가 0에 수렴하고 맥락(선호 재화·전문성) 의존임을 보였고, **시간 슬롯은 선호 재화가 아니라 가용성 제약**이라 과부하 대상 자체가 아니다. 유지되는 진짜 기각 근거: ①비선호재라 이론 적용 부적합 ②UI 개발 비용 ③§13-10 답답함 역리스크 ④V-37 퍼널 실측(신청→방문확정 이탈률)으로 검증 가능한 것을 가설로 선집행할 이유 없음. 결론 동일, 근거를 문헌 정합하게 교체 — 잘못된 "증거 0" 논거가 남으면 향후 실측에서 이탈이 확인됐을 때 재론을 막는다.

**재심-7. V-8/V-15 팔로업 통합 — 조건 강화(신규 발견).**
V-verdict는 기존 D+3 자동 SMS와의 중첩을 지적하며 "통합 조건 하 Top 1 유지"로 판정했다. 코드 재독에서 verdict가 못 본 결함 추가: `run-alert-checks.ts:1356~1363` NEW-A의 기준 시각은 **`createdAt`(주석 자인: "no completedAt field — best available timestamp")**이다. 실제 상담은 며칠 전 예약되므로 대부분의 리드에서 `createdAt`은 이미 3일 초과 → **상담 COMPLETED 처리 직후 첫 크론에서 즉시 발송**된다. 즉 실질은 "D+3 팔로업"이 아니라 "완료 당일 팔로업"이고, 수기 24h 터치(V-8)와 **같은 날 충돌** 확률이 verdict 추정(5일 3터치)보다 높다. 처방 구체화: ①`ConsultationBooking.completedAt` 필드 추가 or 상태전이 시각 기록(소) ②자동 문안을 처방전 재상기(V-15)로 교체 ③수기 실행 시 `followUpSentAt` 선기록으로 자동 억제. 통합 작업량은 여전히 소(0.5~1일)이나 **선행 필수성이 "권고"에서 "필수"로** 오른다.

**재심-8. V-13 vs C-2 — 마스터 플랜과 verdict의 모순 정리.**
마스터 플랜 C-2는 "PARENT 결제 동선 기본화"를 P로, 오너 권고 A(기본화)로 확정했다. V-verdict V-13은 "PARENT 미연결 가정엔 오히려 마찰 — 미연결 시 기존 경로 무변경"으로 조건부 처리했다. 둘은 모순이 아니라 **해상도 차이**이며 병합이 답: C-2는 P 유지하되 실행 정의를 "PARENT **연결 가정**은 학부모 결제 기본 + **미연결 가정**은 기존 학생 경로 무변경(연결 유도만) + 학생 단독 결제 회귀 테스트"로 못박는다. C-2를 "전 가정 학부모 명의 강제"로 읽고 구현하면 파일럿 결제 마찰 = 매출 자해가 된다.

**재심-9. M-41 + V-38 — "최상위 게이트" 이원화 해소(보강).**
두 verdict가 각각 자기 도메인의 게이트(M-41 유입 상한, V-38 터치 예산)를 "최상위"로 선언했고, M-verdict는 추가로 "유입 상한=강사 잔고(M-38)까지 역산하는 이중 게이트" 명문화를 요구했다. 게이트가 세 곳(R3-C·M-41·V-38)에 흩어지면 어느 것도 지켜지지 않는다. 처방: **단일 「파일럿 용량 게이트」 문서 1장**으로 통합 —
- 유입 상한 = min(오너 월 처리용량 역산, 강사 수기 잔고 ×1.3(C-18))
- 터치 상한 = 방문 전 ≤3 · 상담 후~결제 ≤2 · 첫 30일 능동 ≤3 (**자동 발송 4종 합산**: D-1 리마인더·D+3 팔로업·D+7 체크인·매칭수락 리마인더)
- 위반 시 우선순위: 자동 발송이 수기에 우선(수기를 깎는다)
이 문서가 §2 재배치-1의 코어 시퀀스 삽입 대상이다.
