# R3 — 발굴자(biz-improver) 반박·수정: 레드팀 R2 판정 대응

> 작성: 2026-07-13 · biz-improver · 대상: R2-skeptic §1-B(I-1~I-36 판정) + 교차반박 R-1~R-3.
> 원칙: 부당한 판정은 새 근거로 반박, 정당한 지적은 수용·수정. 조건부 생존은 조건 충족법 구체화로 완전 생존 승격 시도.
> 제약 불변: 요금제 v2 확정가·"언제든 해지"·큐레이션 세계관·홈 동결.

## 요약 (300자 이내)

레드팀 판정 36건 중 **수용 28건 · 부분반박 6건 · 전면반박 2건**. 기각 4건은 대응 갈림: I-2·I-26은 **수용**(파일럿 유입 상한=오너 처리용량 R-3 논거가 결정적, 새 SKU는 세계관 긴장), I-19·I-22는 **조건부 반박**(파일럿 연기는 수용하되 "기각"이 아닌 "확장기 승계"로 재분류 — 논거 자체는 유효). I-1 동탄 "강남 우월" 서사는 새 검증 결과 **철회** — 대치·목동 프리미엄 밀도 압도적, 동탄은 밀도 1위 아님. 대신 "신흥 자족도시 고소득 세그먼트 + 방문 이동효율"로 논거 교체(생존). 조건부 생존 15건 중 8건을 조건 충족법 구체화로 완전 생존 승격 시도. 교차반박 R-1(BEP 민감도)·R-2(강사이탈 지표붕괴)는 수용하고 파일럿 안전판 제안 신설.

## 2. 조건부 생존 → 완전 생존 승격 요약

레드팀 조건을 "신규개발 0 / 쿼리 한 줄 / 기존 자산 재사용"으로 충족해 파일럿 기회비용 논거를 무력화:

- **I-4·I-30**: PARENT 다자녀 연결 = 부모앱 코드/QR 기존 자산. 개발 0 → 완전 생존(소구·발동만).
- **I-5**: CMS 카피 토글 기존 기능. I-26(새 SKU)과 분리 → 순수 타이밍 = 완전 생존.
- **I-18**: 대시보드 연기, "대기학생×1.3 수기 잔고" 원칙만 → 완전 생존(CEO §8 최상위 리스크 방어).
- **I-23**: manager-portal-data.ts 쿼리 필터 완화 한 줄 → 완전 생존.
- **I-17**: 시스템 연기하되 파일럿부터 수기 코호트 기록 → 활성 20명 도달 시 데이터 선축적.

## 3. 교차반박 R-1~R-3 수용 + 파일럿 안전판 신설

레드팀 교차반박은 발굴자 안의 사각지대를 정확히 찔렀다. 수용하고 안전판 제안:

### R-1 수용 — BEP "5명"은 낙관 가정치 (시급 인상 민감도)
- 스켑틱 지적: 시급 30k→32~35k(공급실패 헤지 비용)이면 기여마진 21.6만→15만대, BEP 5명→7명. 시니어 트랙 필요 주장 자체가 "30k로 못 잡는다"는 BEP 자기모순.
- **수용**. 발굴자 I-16(행정대행+안정수요)의 진짜 목적이 바로 이것 — **시급 인상 없이 강사를 잡는 비가격 레버**. 즉 I-16은 R-1 민감도의 헤지다. I-19(시니어)는 시급 상단이 필요할 때의 대안 레버. 두 안이 BEP 민감도 양면 대응.
- **안전판 신설 R3-A**: 파일럿 강사 계약에 시급 30k 고정 명시 + "행정대행 가치(수금·정산·매칭·홍보 제거)"를 계약서에 명문화 → 시급 인상 압력 자체를 비가격 가치로 상쇄.

### R-2 수용 — 파일럿 강사 이탈 = 지표 붕괴 (대수의 법칙 부재)
- 스켑틱 지적: 활성 5명을 강사 2~3명이 담당 → 강사 1명 이탈 시 학생 2~3명 동시 공백 = 5→2~3명 BEP 붕괴. 밀도(I-1)와 정면 상충인데 아무도 트레이드오프 안 봄.
- **수용**. 발굴자 I-1 밀도 논리와 R-2 분산 논리의 트레이드오프를 명시적으로 인정.
- **안전판 신설 R3-B**: 파일럿 한정 **의도적 강사 분산**(1강사=1~2학생 상한)으로 단일 이탈의 지표 타격 완화. 밀도(이동효율)는 활성 15명+ 대수의 법칙 확보 후 추구. I-14 재배정 프로토콜은 이 안전판의 실행 도구. → **밀도 vs 분산은 규모 함수**: 파일럿=분산 우선, 확장기=밀도 우선.

### R-3 수용 — 첫터치 수행자=오너 1인 (SLA 시스템화의 허점)
- 스켑틱 지적: I-21 4h SLA를 오너가 직접 소화 = F-11 번아웃. 유입 늘리는 I-2는 오히려 해로움.
- **수용**. I-2 기각의 결정적 보강 근거로 인정(위 표 반영). 
- **안전판 신설 R3-C**: 파일럿 상담 유입 상한 = **오너 월 처리용량으로 역산**(상담 1건당 대면상담+매칭+CS 소요시간 × 오너 가용시간). 유입 확대 제안(I-2 등)은 이 상한 아래에서만. I-21 알림은 "처리량 증대"가 아니라 "누락 방지" 용도로 목적 재정의.
