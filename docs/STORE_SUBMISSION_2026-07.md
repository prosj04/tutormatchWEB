## 4. 스토어 등록 텍스트 초안

- **이름**: Concord — 관리형 1:1 방문 과외
- **부제(iOS)**: 검증된 선생님, 매니저가 관리하는 과외
- **설명(요지)**:
  - 면접·검증을 통과한 선생님만. 전담 매니저가 대면 상담으로 직접 배정해요.
  - 숙제는 자동으로 요일별 배분, 모르는 문제는 밤에 올려도 AI가 바로 답해요.
  - 학부모는 자녀 연결 한 번으로 리포트·결제를 한곳에서 확인해요.
  - (⚠️ 수락 버튼·학생 수락 강조 금지 — 매니저 직접 배정 중심 서술 유지)
- **키워드(iOS)**: 과외,방문과외,1:1,내신,수능,과외선생님,학습관리,중등,고등
- **카테고리**: 교육
- **지원 URL**: https://tutormatch-web.vercel.app (도메인 확보 시 교체)

## 5. 빌드·제출 절차 (결정 후 실행)

1. `eas build --platform all` (EAS 계정·프로젝트 설정 확인) → 2. 내부 테스트 트랙(TestFlight / Play 내부 테스트)에서 4역할 로그인 스모크 → 3. 심사 제출 (Apple 심사 메모에 데모 계정 + "결제는 방문 수업 실물 서비스" 명시)
