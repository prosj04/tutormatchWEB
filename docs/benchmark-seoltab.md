## 1. 전환 설계 핵심 10가지 (설탭이 고객을 모으는 방식)

1. **단일 전환점 = 상담신청.** 사이트 전체의 모든 CTA(히어로, 선생님 카드의 "빠른 매칭받기", FAQ 하단, 각 섹션 버튼)가 `/consult_request` 한 곳으로 수렴한다.
2. **초저마찰 폼.** 이름조차 받지 않는다. 학년(select) + 과목(체크) + 연락처 + 희망 상담시간(select) + 약관 동의가 전부. "5초면 충분"함을 카피로 반복 광고.
3. **리스크 제거 3종 세트.** ①첫 수업 후 불만족 시 100% 환불 ②선생님 무료 변경(변경비용 0원 + 무료수업 추가) ③상담만 해도 학습진단 무료 제공(공짜 미끼).
4. **화면 하단 고정 CTA.** 모든 페이지에서 "딱 맞는 선생님 추천받기" 버튼이 스크롤 내내 고정되고, 버튼 위에 "첫 수업 후 불만족시 100% 환불" 말풍선 툴팁이 항상 붙어 있다.
5. **상단 긴급성 배너.** 상담신청이 많아 순차 안내 중이라는 수요 과잉 연출 + "상담 대기 없는 바로 결제하기" 우회로 제시.
6. **숫자 증거 반복.** 만족도 97%, 수강생 2명 중 1명 3개월 내 성적 상승(모수·기간 명시), 최종합격률 53.3%, 누적 수업·매칭·학생·선생님 카운트업, 교습경력 1년 이상 66%. 모든 수치에 각주(조사 기준·기간)를 달아 신뢰 장치로 사용.
7. **성적 변화의 정형화 표기.** "4등급 → 1등급!" 화살표 패턴, "수학 15점→73점, 30개월만에 58점 상승" + #과목 #전형 #대학 해시태그.
8. **실물 증거 인증.** 합격통지서·성적표 스캔 이미지 위에 학생 사진 + 수강연도 + 한줄 코멘트 오버레이.
9. **학부모 안심 장치.** 관리매니저가 학부모-선생님 사이를 중개(수업 후 안심리뷰 발송, 월간 맞춤 리포트, 매니저 상담). 후기도 학부모 화법 4종으로 구성.
10. **가격 앵커링.** 상세 요금표 대신 "맞춤수업부터 관리까지 이 모든게 월 199,000원~" 한 줄만 노출하고 나머지는 상담으로 넘긴다.

## 2. 페이지별 섹션 구조

### 2-1. 메인(/)

긴급성 배너 → 헤더(여름특강·과목별·선생님·수강후기·입시정보·개념인강·FAQ + [수업결제]) → 시즌 캠페인 히어로(여름방학 컨셉, 모델 사진, 하단 고정 CTA) → 명예의전당(수강생→선생님 성장 스토리, 대학 배지 인용 캐러셀) → 선생님 선별·매칭·관리 책임 3단계 → "선생님이 마음에 안들면?"(변경비용 지원·무료수업 추가·책임수업제도) → 수업 모니터링/피드백 → 내신 공식프로그램 → 무료 학습컨설팅 브릿지("단 5초, 상담신청 남기기") → 100% 환불 보장 밴드 → 만족도 97% → 서비스 소개(국내최초 온라인과외 오리지널) → 내신 프로그램 상세(시험 대비전략→내신 맞춤수업→시험 결과리뷰, AI 성취도 추적) → 질문 유도 교수법 → 인강 번들(1과목 과외 = 국영수 인강 무제한) → 성적상승 통계(2명 중 1명, 모수 각주) → 학부모 소통 3종(안심리뷰·맞춤리포트·매니저 상담) → 학부모 후기 4개 캐러셀 → 누적 통계 카운터 4종 → STEP1~4 진행 프로세스(클릭 아코디언: 신청→레벨테스트→맞춤수업→학습보고) → 가격 앵커(월 199,000원~) → FAQ 5개(아코디언) → 최종 CTA → 푸터(약관·환불규정·개인정보·회사소개·브랜드 철학·사업자 정보·교습비 안내).

### 2-2. 선생님(/tutor)

다크 히어로(손글씨 개인화 "○○와 잘 맞는 선생님, 설탭은 있습니다" + [만나보기] 앵커 버튼) → 통계 카운터 3종(누적 매칭 횟수·첫 수업 매칭 만족도·누적 선생님 수, 각주) → 학생 인터뷰 2컷(좌: 학생 "이런 수업 원해요 👀" / 우: 선생님 "이런 수업 잘해요 😎" — 해시태그 칩으로 니즈↔강점 매칭 연출) → **이달의 선생님 캐러셀**(중앙 포커스형; 카드 구성: 해시태그 배지 3개(#수능수학만점 등) + 프로필 사진 + 대학·학과(전형) + 이름(나이) + 3줄 스토리 + 과목 칩 + 경력 배지("10년 이상") + 대학 문양 워터마크 배경 + 카드별 [빠른 매칭받기]) → "설탭 선생님이 특별한 이유 3가지"(Q&A 반박형: "다 같은 SKY 아닌가요?"/"대학생이라 무책임하지 않나요?"/"교습 경험 있나요?" — 서류·음성테스트·모의수업 검증, 수업 후 학부모 공유, 경력 1년+ 66%) → 성적표 인증 후기 12건 그리드("수학 15점→73점, 30개월만에 58점 상승" + 지역·학교유형·학년) → 선생님 변경 보장(변경 비용 0원) → [맞춤 선생님 제안 받기] → 가격 앵커 → 환불 보장 → 푸터.

### 2-3. 수강후기(/review)

다크 히어로("성적 상승 후기를 만나보세요") → 성공사례 캐러셀("4등급 → 1등급! 고려대학교 입학" + #국어 #정시 #고려대 해시태그, 대학 문양 워터마크) → 통계 밴드(2명 중 1명 3개월 내 상승) → 합격통지서 실물 인증 카드 3종(스캔 이미지 + 학생 사진·수강연도·한줄 코멘트 오버레이) → 고민 카테고리별 상세후기(#성적정체 #기초개념부족 #자신감하락 #목표부실) → 전환 CTA.

### 2-4. 상담신청(/consult_request) — 폼 필드 상세

| 순서 | 필드 | 형식 | 비고 |
|---|---|---|---|
| 0 | 혜택 배너 | 이미지 | 시즌 프로모션(무제한 매칭·아이패드 무료 대여·무료수업 최대 8회) |
| — | 헤드라인 | 텍스트 | "상담신청만 해도 학습진단 100% 제공" |
| 1 | 학년 | select | "26년도 기준 학년" 라벨, 예비중1~N수 |
| 2 | 과목 | 체크박스 | 국어/수학/영어/과학/사회 |
| 3 | 연락처 | tel input | placeholder 010-1234-5678 |
| 4 | 희망 상담 시간 | select | 시간대 슬롯. 일부에 "(전문 학습 설계사와 상담 가능)" 라벨로 특정 슬롯 유도 |
| 5 | 약관 | 체크 3종 | 전체 동의 / [필수] 개인정보 / [선택] 마케팅 |
| 6 | 제출 | 버튼 | "상담 신청하기" |

- 이름 필드 없음. 제출 후 안내: "신청 후 1영업일 내에, 대표번호로 상담이 진행됩니다."
- 별도 도메인 consult.seoltab.com 은 이 페이지로 308 리다이렉트(광고 유입용 단축 경로).

### 2-5. 개념인강(/smart_content)

과외 1과목 신청 시 국·영·수 개념인강 무제한 번들. 과외→인강→자습 3단계 사이클. (Concord에는 인강이 없으므로 구조만 참고, 미채택.)

## 3. 디자인 언어

- 보라(#7C5CFC 계열) 단일 브랜드 컬러. 다크 네이비 섹션 ↔ 라이트 섹션 교차로 리듬감.
- 큰 국문 2줄 헤드라인, 강조어에만 포인트 컬러.
- 해시태그 칩을 정보이자 장식으로 광범위 사용(선생님 강점, 후기 카테고리, 학생 니즈).
- 일러스트보다 실물 사진·스캔(모델 컷, 성적표, 합격통지서) 위주.
- 모든 통계에 작은 각주(조사 기준·기간) 병기.
- 상단 긴급성 배너 + 하단 고정 CTA로 화면 상·하단을 전환 장치로 상시 점유.
