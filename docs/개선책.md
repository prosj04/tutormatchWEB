# 개선책 (유형별 · 단권화)

> 발굴 249건 + 확장 63건에서 살아남은 실행 항목을 유형별로 압축. 발굴ID·라운드·판정 이력은 뺐다.
> 시기 — **P** 파일럿 즉시 · **A** 활성 5~15 · **B** 15~50 · **C** 50+/확장.

## 제품·데이터

- **계측 원장 단일화 (P)** — GA4 + 여정 이벤트 6종(신청·방문확정·방문완료·상담완료·결제·첫수업) + 오프라인(진단서 채널) 스티칭. 하나의 작업, 분리 발주 금지.
- **진단서·월간 리포트 운영 개시 (P)** — 기구현. SOP로 실입력·cron 발송 강제, 케어로그를 리포트에 편입.
- **숙제 자동분배·템플릿 UX 눈검증 (P)** — 기구현. 강사 실사용 순회로 확인.
- **강사 정산 투명 UI (P)** — 예정·확정·지급 3상태 + 3.3% 실수령 표기.
- **매칭 근거 체인 (A)** — matchReason 스키마 기반 배정 근거 데이터화. 성향 태그 15개(어휘 고정)·온보딩 설문 UI.
- **리포트 코퍼스화·성적 추이 이벤트 (A)** — 3개월+ 축적. 비교 UI 금지.
- **AI 보조 (A)** — 상담요약 초안·리포트 요약·Q&A 보조(키 활성 후, 매니저 검수). 평점화 금지.
- **매칭 AI 브리핑 (B)** — 매니저 내부 도구(노출면 기준 세계관 무충돌). 강사 풀 규모 후.

## 마케팅·유입

- **강사 채용 공고 최선행 (P)** — 에타·알바몬. 유입보다 6주 앞. 공급이 병목.
- **용량 게이트 안의 유입만 (P)** — 유입 상한 = 오너 처리용량 역산. 리드0·CAC 40만 시 중단 규율(주간 수기).
- **여름 6주 캠페인 (발동 A)** — 착수 Top의 선행 1~9 완료 후 점화. 상위플랜 전환·유료광고 0·확정가 불변.
- **지역 콘텐츠·SEO (A)** — 옆집엄마 학교명 시리즈(실명·정보:홍보 4:1)·지식iN(주 2~3건)·학교명 롱테일 SEO(수확 3~6개월)·카페 공식제휴(후기 3건 게이트·CAC≤20만)·당근(5만 테스트)·인스타 지역(후기 3건+·CAC≤20만).
- **스마트플레이스·리뷰 (A)** — 등록(사진 후)·자발 후기 협조(대가 표시).
- **리퍼럴 비가격 우대 (A)** — 우선 상담·매니저 지정 등. **할인 절대 불가.**
- **학교단위 설명회·지역 유지 네트워크 (B)** — 5~8가정 처리용량 게이트 후.

## 운영·전환

- **용량 게이트 문서 1장 (P)** — 유입 상한 + 터치 예산(방문 전 ≤3 · 상담후~결제 ≤2 · 첫30일 ≤3, **자동 발송 4종 합산**) + 강사 수기 잔고 ×1.3. 이후 모든 유입·터치의 발동 조건.
- **상담 3막 극장 (P)** — 3막 각본 → 상담 중 진단서 실입력 → 종료 시 처방전 프린트 전달 → 배정 근거 구술. 무개발.
- **첫 30일 온보딩 여정 (P)** — 방문 안내서·첫수업 D-1 3자 문안·마일스톤·저점 24h 개입·위기 3색 신호등(주 1회 수기). 능동 터치 ≤3(예산 내).
- **팔로업 단일 파이프 (P)** — completedAt 소수정 → 자동 D+3 = 처방전 재상기 → 수기 시 자동 억제 → 미결제 5분류 태깅 → 시즌 큐. CRM은 3터치 상한 안에서만.
- **결제 마감 장치 (P)** — 100% 환불 앵커 + 완료 화면 + 빌링 등록 노출(기구현) + PARENT 기본화(연결 가정 한정·회귀 테스트).
- **수업확인 정합 + 알림 문안 전수 스윕 (P)** — D+7 비과실 이월 소수정 + 느낌표·세계관 위반 문안 실물 제거.
- **케어·리텐션 (P)** — 이탈 조기경보 체크리스트 · 재결제 리추얼(기말 직후·각주 격리) · 후기 요청=재결제 게이트(매니저 카톡 경유) · 형제/가정 매니저 연속성 소구.

- **재배정·경력증명·온보딩 (P수칙~A)** — 무마찰 재배정 프로토콜 · 경력증명 템플릿(자동 발급 A) · 온보딩 4단계 체크리스트 · 방문 안전 프로토콜 · 첫수업 QA 전수.

- **관망 원칙 1줄씩 (P)** — 자본 배분 순서(가정당 깊이 → 지역 밀도 → 신규 지역) · B2G 관망(브랜드 슬롯만, 매출축 금지).
