# 결정 기록 (ADR)

번복 가능성이 있는 결정을 append-only로 남긴다. **기존 문서를 고쳐 쓰지 말고**, 결정이 바뀌면 새 번호로 문서를 만들어 이전 것을 "대체 대상"으로 지목한다.

여기는 배경 문서다 — 자동으로 로드되지 않는다. **실행 규칙은 `CLAUDE.md`·`docs/BUSINESS_DIRECTION.md`·`.claude/rules/`에 두고**, 여기에는 "왜 그렇게 됐는지"만 남긴다.
