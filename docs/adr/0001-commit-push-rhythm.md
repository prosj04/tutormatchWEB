# 0001. 커밋·푸시 리듬 — 승인 대기 폐지

- 상태: 채택 (2026-07-26)
- 대체 대상: "커밋은 자동, push는 오너 승인" (2026-07-13), "논리 단위 완료 시 항상 커밋·항상 푸시" (2026-07-23)

## 맥락

main push가 곧 프로덕션 배포라 초기에는 푸시마다 오너 승인을 받았다. 승인 왕복이 병목이 되어 2026-07-23에 "항상 푸시"로 풀었으나, 커밋·푸시 단위가 명확하지 않아 세션마다 리듬이 달랐다.

## 결정

- **기능 하나가 완성되면 커밋한다.**
- **한 번의 작업(목표)이 끝나면 푸시하고 보고한다.**

승인 대기 없음. 커밋을 기능 단위로 쪼개는 이유는 부분 롤백 보장이다.

## 결과

- 스테이징은 명시적 경로만 — 동시 세션의 미커밋 파일이 딸려가면 안 된다.
- force push·`main` 히스토리 재작성은 여전히 오너 확인.
- 서브에이전트는 커밋하지 않는다 (본체가 수행).
