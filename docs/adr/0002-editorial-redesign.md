# 0002. 디자인 시스템 v3 "Editorial" 도입 — v2 핸드오프 대체

- 상태: 채택 (2026-09-30), 브랜치 `feat/editorial-redesign` 에서 구현 완료 (`main` 미병합 — 오너 확인 후 병합). 기록: [`docs/design/REDESIGN_2026-09-30.md`](../design/REDESIGN_2026-09-30.md)
- 대체 대상: `docs/BUSINESS_DIRECTION.md` §7 의 v2 전제 조항 5건 (아래 §3)
- 관련 문서: 스펙 [`docs/design/DESIGN_SYSTEM_V3.md`](../design/DESIGN_SYSTEM_V3.md) · 구현 정본 `src/app/ds.css` · 보관된 v2 패키지 [`docs/archive/design-handoff-v2/`](../archive/design-handoff-v2/)

## 1. 맥락

v2 는 외주 디자이너 핸드오프(그린/블루 × 라이트/다크 4조합, 루트 `design handoff/`)였다. §7 은 그 전제 위에서 "디자인을 다시 만들지 말 것 / 핸드오프 CSS 를 한 글자도 고치지 말 것 / 적용 범위는 로그인 후 화면만"을 규칙으로 못박았다. 이 규칙의 목적은 **오너의 취향 결정을 AI 가 재해석하지 못하게 막는 것**이었고(§11 반복 교정 3번 "재해석 → 재현"), 디자인 자체의 영속성을 보장한 것은 아니었다.

2026-09-30 오너 지시:

> "UI 전면 개편, 기존 디자인은 싹 갈아엎어"

즉 취향 결정 자체가 갱신되었다. §14-18(매몰비용 제로 — "별로다"는 즉시 폐기가 정답)에 따라 v2 를 방어하지 않고 교체한다.

## 2. 결정

1. **디자인 시스템 v3 "Editorial" 을 도입한다.** 인쇄 지면 문법(종이 바탕·잉크 글자·세리프 헤드라인·헤어라인 구분선·넓은 여백)으로 마켓플레이스/SaaS 문법(둥근 카드 그리드·컬러 배지·그림자 호버)을 대체한다. 근거: 큐레이션 서비스는 "고르는 화면"이 아니라 "정해주는 지면"이다(§11 관통 논제).
2. **적용 범위는 공개 페이지를 포함한 전면**이다. 홈·pricing·tutors·reviews·faq·login 도 대상이다.
3. **구현 정본은 `src/app/ds.css` 단일 전역 스타일시트**다. v2 의 파일 분할(`landing-v2.css` `.lp2-` 접두사 / `concord.css` / `concord-portal.css` / `concord-admin.css` / 브리지 CSS)은 통합·폐지된다.
4. **토큰 이름은 v2 를 승계하고 값만 바꾼다.** 덕분에 토큰을 경유한 기존 코드는 자동으로 v3 를 따른다. 하드코딩 색이 남아 있으면 그것이 곧 결함이다.
5. **v2 패키지는 지우지 않고 보관한다.** 루트 `design handoff/` → `docs/archive/design-handoff-v2/`. 시안 HTML 20종·`DESIGN_SYSTEM.md`·`ROUTE_MAP.md`·`IMPLEMENTATION_CONTRACT.md`·`MOBILE_HANDOFF.md`·`FRONTEND_BUILD_SPEC.md`·레퍼런스 PNG 전량.
6. **새 마케팅 카피를 만들지 않는다.** 문구는 기존 CMS 키·코드 폴백 그대로 두고 디자인만 바꾼다. 카피 변경은 별건 지시 사안이다.

## 3. 대체되는 §7 조항 (5건)

| 구 조항 (v2 전제) | v3 기준 |
|---|---|
| "디자인을 다시 만들지 말 것 — 디자이너 핸드오프 CSS 를 한 글자도 안 고치고 그대로 import" | v3 스펙(`DESIGN_SYSTEM_V3.md`)이 사양이고 `src/app/ds.css` 가 구현 정본이다. 핸드오프 CSS 무수정 import 는 종료. **재해석 금지 원칙 자체는 유지** — 대상이 v2 CSS 에서 v3 스펙으로 바뀐 것이다. |
| "Pretendard 1.3.9 고정" | Pretendard = 산세리프(본문·UI), **Noto Serif KR = 세리프(목소리: h1·h2·디스플레이·큰 숫자·인용)** 2종 체계. 버전 고정 조항은 해제. |
| "신 디자인 적용 범위 = 로그인 후 화면(포털·앱)만. 공개 페이지 수정 절대 금지" | 공개 페이지 포함 전면 개편. 이 금지는 해제된다. |
| "테마: 그린/블루 × 라이트/다크 4조합" | Evergreen(기본, `data-color=green`) / Navy(`data-color=blue`) × 라이트·다크 = 조합 수는 4 유지, **값은 종이·잉크·딥그린/네이비로 전면 교체.** |
| "값 눈대중 이식 금지, 토큰 변수만 사용, 아이콘은 icons.js 단일 소스" | 토큰 경유 원칙 유지. 아이콘 단일 소스 원칙 유지하되 출처는 보관된 v2 `icons.js` 에서 이식된 `src/lib/icons.ts` 다. |

## 4. 유지되는 규칙 (v3 에서도 그대로)

바뀐 것은 스킨이지 헌법이 아니다. 다음은 §7 과 §13 에서 계속 유효하다.

- **기능 축소 절대 금지.** 시안이 기존 기능보다 단순하면 축소 구현하지 말고 기능 보존형 재시안.
- **사진 원본 비율 유지** — 크롭·비율 왜곡 금지, 리사이징만. `object-fit:cover` 로 비율을 깎지 않는다. 1:1 카드는 1:1 로 준비된 자산만.
- **이미지 생성 규칙** — 인물 사진 생성 금지(오너 실촬영분만), 비인물은 자리 + "어떤 느낌의 사진이 오면 좋을지" 메모 우선.
- **캐러셀은 좌우 이동만.**
- **목업·예시 박스는 스크롤을 따라다니지 않는다** (7회 재지시) — 항목 옆 고정·중앙 정렬·섹션 밖 이탈 금지, 항목이 바뀌면 목업 내용도 항목별로 바뀐다.
- **스크롤텔링 종료 후 01·02 항목은 다음 페이지로 분리** (4회 재지시).
- **롤백 가능성 보존** — 기능 단위 커밋, 부분 되돌림 가능(§14-14).
- **미학 원칙 §13 전문** — 짜침 배제, 박스-안-박스 금지, 효과는 지각 문턱값, 템포=위계, 파생 수치 노출 금지, 광학 정렬. v3 의 "헤어라인·여백·라운드 최소"는 이 원칙의 강화판이지 예외가 아니다.

## 5. 롤백 방법

세 층위로 되돌릴 수 있다.

1. **전체** — v3 작업은 `feat/editorial-redesign` 브랜치에 격리돼 있다. `main` 을 병합하지 않으면 v2 가 그대로 살아 있다.
2. **부분** — 병합 후에는 기능 단위 커밋을 골라 `revert`. 광범위 변경을 한 커밋에 뭉치지 않는 것이 이 롤백의 전제다(ADR 0001·§14-14). 커밋은 기반(토큰·공용 CSS·크롬) 1개 + 영역별(랜딩·공개·전환·학생·학부모·선생님/매니저·관리자) 7개로 나뉜다. 영역 커밋은 기반 커밋 위에서만 성립한다 — 구 CSS 가 기반 커밋에서 삭제됐기 때문에, 영역 하나만 v2 로 되돌리면 그 영역은 구 클래스를 참조한 채 스타일 없이 렌더된다. 영역 단위 롤백이 필요하면 해당 영역 커밋과 함께 구 CSS 를 git 히스토리에서 복원한다.
3. **자산** — v2 시안·토큰·CSS 원본은 `docs/archive/design-handoff-v2/` 에 전량 보존. 삭제된 파일 없음. 구 CSS 파일(`concord-portal.css` 등)은 git 히스토리에 남는다.
