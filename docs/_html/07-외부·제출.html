0. 한눈에 보는 Concord

Concord Private Tutoring은 면접·검증된 강사와 전담 매니저가 대면 1:1 과외를 매칭·관리하는 프리미엄 에듀테크 플랫폼입니다. 아이디어 단계가 아니라 웹 4역할 포털·결제·AI 질답·학습관리가 모두 작동하는 완성된 소프트웨어입니다.

1. 공개 페이지 — 첫인상과 신뢰 설계

로그인 없이 접근하는 마케팅·전환 페이지입니다. 서사는 **"성적보다 습관이 먼저 바뀐다"**는 불안 해소 카피를 축으로 합니다.

1.1 홈 (랜딩)

히어로 → 문제 제기 → 검증/매칭/관리 3단 약속 → 프루프 카드 → 상담 CTA로 이어지는 단일 전환 퍼널. 우상단 무료 상담 버튼이 모든 페이지에 상주합니다.

1.2 요금제

월정액 선불 8개 플랜(38만~112만 원)을 과목·횟수 조합으로 제시. 강사 시급 30,000원 정산 구조 위에 평균 마진율 34.2%를 확보하는 단가 체계입니다.

1.3 강사진 / 강사 상세

검증을 통과한(approved) 강사만 노출됩니다. 상세 페이지는 과목·경력·소개를 담아 "사전 검증된 강사"라는 핵심 가치를 시각화합니다.

1.4 후기

성적 수치가 아니라 습관·태도 변화 중심의 후기 카드. "대치동 학원을 옮겨다녔는데 매니저님이 직접 상담…", "모르는 문제를 밤에 올리면 AI가 바로 답을…" 등 제품 차별점이 그대로 사회적 증거가 됩니다.

2. 학생 여정 — 상담부터 수업 진행까지

Concord의 제품 북극성은 **"화면 너머가 아니라 옆자리에서"**입니다. 학생 대시보드는 학습 단계(Journey Stage)에 따라 다른 화면을 보여주며, 각 단계가 실제 DB 상태에서 자동 산출됩니다.

단계: 상담대기 → 매니저 배정 → 매칭 진행 → 배정 확인 → 첫 수업 대기 → 수업 진행(ACTIVE)

2.1 ① 매칭 진행 (상담 완료)

대면 상담이 끝나면 "곧 맞춤 선생님을 추천해 드릴게요" 상태 카드가 뜨고, 상담 메모(예: "수학 내신 대비, 주 2회 대면 희망")가 그대로 이어집니다.

2.2 ② 배정 확인 — 핵심 차별점: 이유를 설명하는 매칭

매니저가 배정한 강사가 추천 이유("학생 성향(차분한 설명 선호)에 맞춰 추천드립니다")와 함께 안내됩니다. 일방 통보가 아니라 왜 이 선생님인지 설명하는 매칭이며, 미스매치 시 무료 재매칭을 보장합니다.

2.3 ③ 첫 수업 일정 대기

배정이 확정되면 강사가 첫 수업 날짜를 설정하고, 그 전까지 "첫 수업 일정 조율 중" 상태를 유지합니다.

2.4 ④ 수업 진행 대시보드 (ACTIVE) — 제품의 심장

수업이 시작되면 학생은 통합 학습 대시보드를 받습니다. 한 화면에:

  • 캘린더 학습 플래너 — 날짜별 할 일("미적분 개념정리 p88 예제 4개" 등), "이전 날에서 복사" 재사용
  • 담당 선생님 카드 + 매니저 케어 기록("2주차 점검 — 과제 이행률 양호…")
  • 선생님 코멘트와 학습 목표(정량/정성 목표 분리)
  • 질문(Q&A) 스레드 — 아래 2.5

2.5 ⑤ AI + 강사 질답 (Q&A) — 두 번째 차별점

학생이 모르는 문제를 올리면 Claude AI가 즉시 1차 답변하고, 담당 강사가 이어서 확인·보강합니다. 대시보드 하단(2.4)에서도 동일 스레드가 보이며, "해결됨" 플래그로 관리됩니다.

예시: "미분계수 정의에서 극한이 존재하지 않으면 미분 불가능인가요?" → AI 즉답(순간변화율 정의) → 강사 보강("연속이지만 미분 불가능한 예 y=|x| 를 꼭 기억하세요") → 해결됨.

이 구조는 "밤에 질문해도 방치되지 않는다"는 후기(1.4)의 실체이자, AI 토큰 = 원가 통제 가능한 부가가치라는 사업적 의미를 갖습니다.

2. 실현가능성 (Solution) — 창업 아이템의 구체화

2-1. 솔루션 개요

"검증·매칭·관리를 플랫폼이 대신 떠안고, 그 편익을 프리미엄 마진으로 회수한다."

Concord는 학부모가 개별로 부담하던 (①검증 ②탐색·재탐색 ③관리·모니터링) 비용을 플랫폼이 집합적으로 단 한 번 수행해 모든 수요자에게 재사용시키는 구조이다. 학부모는 "검증된 강사를 매니저에게 배정받고 그 이후를 앱으로 관리 받는" 편익을, Concord는 수업료 수취액과 강사 정산액의 차액을 매출로 수취한다.

2-2. 서비스 플로우

3. 성장전략 (Scale-up) — 시장·수익모델·확장 로드맵

3-2. 수익 모델

  • 월 정액 수강료 선불 — 학부모가 매월 수업료를 선불 결제.
  • 강사에게 시급 30,000원/h 기준 월말 정산 (2026-07-04 확정), 그 차액이 플랫폼 매출. 8개 플랜 평균 마진율은 약 34.2% (범위 29.9~42.0%). 상세 산출은 부속 재무계획 §1-3.
  • 부가 매출: 파일럿 검증 후 향후 (i) 매니저형 학원 SaaS 라이선스, (ii) 학습 데이터 기반 진로·컨설팅 상품, (iii) B2B 학원 파트너십.

3-3. 콜드스타트 → 파일럿 → 지역 확장 로드맵

시기 목표 실행
Phase 0: 공급 확보 (개시 D-8 ~ D-0) 검증된 강사 5~10명, 매니저 1명 확보 대학 커뮤니티·지인, "창립 멤버" 조건(수수료 우대)
Phase 1: 파일럿 (개시 후 ~10주) 서울·분당 5~10가정 유상 파일럿 지인·지역 맘카페, 후기·사진 사용 동의 조건 할인
Phase 2: 증거 전환 (~6개월) 실촬영·실후기·성적 향상 사례 사이트 반영, MK-6 수치 교체 파일럿 결과로 마케팅 자산 교체
Phase 3: 유료 채널 개시 (~12개월) 활성 학생 50명, 강사 20명 네이버 스마트플레이스·검색광고 소액, 카카오톡 채널, GA4 계측 위 CAC 검증된 채널만 증액
Phase 4: 지역 확장 (~24개월) 활성 학생 100명 이상, 서초·용인·수지 확장 지역별 매니저 채용 (변동비 구조), 자동 강사 추천 알고리즘 도입
Phase 5: 전국·B2B (~36개월) 활성 학생 150~170명, 학원 SaaS 파일럿 타 지역 매니저 프랜차이즈형, 학원 백오피스 SaaS 검토

3-4. 경쟁 분석 요약

  • 콴다과외/설탭: 비대면 태블릿 카테고리. Concord는 정면 경쟁이 아니라 "다른 카테고리"(대면 프리미엄)로 포지셔닝하여 회피.

  • 이미 만든 제품: 웹 플랫폼(4역할 포털·결제·AI·CMS)과 모바일 백엔드가 실서비스 수준으로 완성되어 있음. 아이디어가 아니라 작동하는 소프트웨어가 심사 대상.
  • 도메인 밀착: 강사 경력에서 도출한 문제 인식(검증 비대칭, 매칭 실패 비용, 관리 부재)이 그대로 제품 설계에 반영됨.

0. 한 장 요약 — 지금 무엇을, 왜

Concord는 "검증된 대면 1:1 과외 + 전담 매니저 관리"를 소프트웨어로 표준화한 프리미엄 에듀테크입니다. 제품은 이미 완성되어 작동합니다(4역할 포털·결제·AI 질답·학습관리). 남은 것은 아이디어 검증이 아니라 시장 검증과 성장 실행입니다.

경영자께 드리는 제안의 골자:

  1. 지금이 파일럿 개시 적기 — 제품 리스크가 제거된 상태이므로, 자본은 개발이 아니라 분당 1~2개 동 집중 파일럿에 투입합니다.
  2. 공급(강사) 채용을 수요 모집보다 2~6주 먼저 가동합니다(모집 후 매칭 실패가 최대 유지 리스크).
  3. CAC ≤ 20만 원 채널만 파일럿에서 사용하고, 주간 계측으로 2주 무반응 채널은 교체합니다.
  4. 지원금 1억 원 확보 시 인건비·마케팅·모바일 앱에 배분해 12개월 내 자립을 목표합니다.

1. Problem — 검증 비대칭

  • 사교육비 총액 29.2조 원(2024, 4년 연속 최고치), 참여율 80.0%. 1:1 과외는 참여학생 1인 월 43.9만 원의 최고단가 영역.
  • 강사 공급은 과잉이나 학부모가 실력·성실성·궁합을 사전 검증할 수단이 없음 → 검증비용이 매 가정·매 계약마다 중복 지불.
  • 매칭 실패 시 재탐색·환불 분쟁·학습 공백. 매칭 이후 진도·과제는 "깜깜이".

2. Solution — 검증·매칭·관리를 플랫폼이 대신

  • 강사 공급은 과잉이지만, 학부모가 실력·성실성·궁합을 사전 검증할 수단이 없음 → 검증 비용이 매 가정·매 계약마다 중복 지불됨.
  • 매칭 실패 시 재탐색·환불 분쟁·학습 공백. 매칭 이후 진도·과제는 "깜깜이".

Solution — 검증 · 매칭 · 관리를 플랫폼이 대신

  1. 검증: 면접 · 서류 · 범죄경력조회를 통과한 강사만 등록
  2. 매칭: 전담 매니저가 대면 상담에서 성향·수준을 파악해 직접 배정 → 미스매치 시 무료 재매칭 보장
  3. 관리: 주간 숙제 자동 분배 · Claude AI 질답 · 학습 리포트로 수업 밖 과정을 학부모에게 투명 공개

포지셔닝: 콴다과외·설탭(비대면 태블릿)과 김과외·숨고(나열형 중개) 사이의 빈 카테고리 — "검증된 대면 1:1 + 매니저 관리" 선점. "화면 너머가 아니라, 옆자리에서."

Product — 아이디어가 아니라 작동하는 소프트웨어

  • 웹 플랫폼 완성: 4역할 포털(학생·강사·매니저·관리자) · 토스페이먼츠 결제(서버 검증) · 캘린더 학습 플랜 · 숙제 자동 분배 · AI 질답 · CMS · 알림 배치
  • 모바일: 백엔드 API 58종 완성 · React Native 앱은 지원금 활용 개발 예정
  • 1인 풀스택 자체 개발 (Next.js 14 · Prisma · Supabase · Vercel)
