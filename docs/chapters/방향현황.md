# 방향·현황

> Concord 문서집의 첫 관문. 세계관·원칙·사업 골격·현재 상태를 한 문서로 파악한다.
> 원칙의 정본은 [`docs/BUSINESS_DIRECTION.md`](../BUSINESS_DIRECTION.md) — 충돌 시 정본이 우선한다. 갱신: 2026-07-14.

## 1. 세계관·정체성

Concord는 서울·동탄의 프리미엄 1:1 방문 과외. 플랫폼이 아니라 **큐레이션 서비스**다.

상품은 과외가 아니라 **"학부모가 비교·검증·선택하지 않아도 된다"는 판단의 위임**이다. 대표가 선생님 전원을 직접 대면 면접(인품·학력·신원·수업 실력)하고, 매니저가 방문 상담에서 학생 성향을 파악해 적합한 선생님을 배정한다. 선택 피로의 제거가 곧 상품이다.

핵심 철학은 성향 매칭 — 학생의 공부 스타일에 맞는 교육 철학의 선생님을 추천한다. 두 번째 축은 수업 밖 관리 — "수업보다도 수업 이후 학생의 공부가 성적을 가릅니다." 숙제·공부계획 시스템 등록, AI 즉시 답변 + 선생님 답변, 월간 리포트 공유.

**금지 UX** — 마켓플레이스 문법의 재삽입을 막는다.

- 선생님 비교·선택 UX 금지. 배정은 매니저 권한.
- 수락 버튼 강조 금지 (형식적 절차), 학생 측 거절·재배정 플로우 금지.
- 평점·별점 수집·노출 금지.
- 할인 구조·할인률 뱃지 금지.

## 2. 카피 헌법·미학 요약

정본: [`BUSINESS_DIRECTION.md`](../BUSINESS_DIRECTION.md) §12(카피)·§13(미학). 아래는 요지.

**카피**

- 평서 확언 "~합니다" 종결. 느낌표·의문문·이모지 0.
- 주어는 "우리는". 최상급은 클라이맥스 1회만("최고의 선생님만") — 신뢰는 형용사가 아니라 절차의 사실로.
- 헤드라인은 한 줄. 조건·단서는 본문이 아닌 각주로("*환불정책 참고").
- CTA만 해요체·명사형("선생님 추천받기"). 도입·설명 문장 금지, 파생 수치(총시간·환산·할인율) 노출 금지.
- 후기·인용은 정반대 — 각기 다른 사람의 질감, 생말투(반말체 금지), 원문 그대로.

**미학** — "짜침" 배제. 점잖고, 담백하고, 비싸 보이게.

- 박스-안-박스·카드-안-카드 금지. 요소는 지면 위에 직접.
- 효과는 지각 문턱값(페이드 5%) — 보이면 이미 과하다.
- 템포=위계(중요한 것은 느리게), 위계는 투명도로, 사진 크롭·비율 왜곡 금지.
- 새 요소의 기본값은 '포장 없음'. 초안 완성 후 감산 패스 1회.

## 3. 사업 골격

**요금제 — 오너 확정가, 불변.** 할인 구조·요금 공식 없음. 코드값이 진실이다.

| 구성 (4주) | 중등 | 고등 |
|---|---|---|
| 주1회 2h | 38만 | 43만 |
| 주1회 3h | 55만 | 58만 |
| 주2회 2h | 76만 | 78만 |
| 주2회 3h | 106만 | 112만 |

표기는 "월"이 아니라 "(4주)". 선생 정산 시급 기본 30,000원, 차등 프리셋 32/34/40k(관리자 수동 지정).

**노스스타 플로우.** 학생이 신청 또는 결제하면 결제 학생은 치프매니저에게 자동 배정되고, 매니저가 방문 상담에서 성향 파악·학습 진단 후 적합한 선생님을 배정한다. 선생님이 첫 수업일을 지정해 수업을 시작하고, 숙제는 1주 분량을 한 번에 입력하면 요일별 가중 자동 분배(템플릿 재사용)된다. 수업 확인은 자동완료 폐지 — 선생님이 완료/사유를 선택하고, 학생 과실은 정산 포함·비과실은 마지막 수업으로 이월, 3자 알림. 이후 월간 리포트와 빌링키 자동갱신·정산으로 이어진다.

**리스크 제거.** 첫 수업이 맞지 않으면 100% 환불, 선생님 교체 비용 0원, 언제든 해지. 구독 일시정지는 학부모에게 노출하지 않는 제도(매니저 수동, 최대 35일).
