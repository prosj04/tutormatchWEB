## 1. IR 요약 — 한 장 요지

**Concord는 "검증된 대면 1:1 과외 + 전담 매니저 관리"를 소프트웨어로 표준화한 프리미엄 에듀테크입니다.** 제품은 이미 완성되어 작동합니다. 남은 것은 아이디어 검증이 아니라 시장 검증과 성장 실행입니다.

- **Problem** — 강사 공급은 과잉이지만 학부모가 실력·성실성·궁합을 사전 검증할 수단이 없습니다. 검증 비용이 매 가정·매 계약마다 중복 지불되고, 매칭 이후 진도·과제는 확인 채널이 없습니다.
- **Solution** — 검증(면접·서류·범죄경력조회) · 매칭(매니저 대면 상담 후 직접 배정, 미스매치 시 무료 재매칭) · 관리(숙제 자동 분배 · Claude AI 질답 · 학습 리포트)를 플랫폼이 대신 수행합니다.
- **Product** — 4역할 포털 · 서버검증 결제 · 학습 플랜 · AI 질답 · CMS · 정산/퍼널/감사로그 백오피스까지 작동하는 소프트웨어. 1인 풀스택 자체 개발.

| 핵심 지표 | 값 |
|---|---|
| 요금 | 4주 정액 선불 38만~112만 원 (8개 플랜) |
| 강사 정산 | 시급 30,000원/h (확정) |
| 평균 마진율 | **34.2%** (플랜별 29.9~42.0%) |
| 학생 1인 월 기여마진 | 약 21.6만~24.2만 원 |
| BEP | Phase 1 활성 **5명** / Phase 2 활성 **14명** |
| LTV/CAC 목표 | 5:1 이상 |
| 3개년 목표(기본) | 활성 학생 170명 · 누적 거래액 약 19.1억 원 · 기여마진 약 6.3억 원 |
| Ask | 지원금 1억 원 — 인건비 30 · 사업화 25 · 마케팅 25 · 운영 15 · 예비 5(%) |

## 2. 사업계획 (PSST)

### 2-1. Problem — 검증 비대칭

#### 시장 배경 (2025년 조사 실측)

- 사교육비 총액(2025): 약 **27.5조 원** — 전년 대비 5.7% 감소, 5년 만의 첫 감소. 참여율도 4.3%p 하락.
- 그러나 **참여학생 1인당 월평균 사교육비는 60.4만 원으로 오히려 증가(+2.0%)**.
- 소득별 밴드: 월소득 800만 원 이상 가구 **66.2만 원** vs 300만 원 미만 가구 **19.2만 원**.
- 독해: 총액은 줄고 참여 가구는 더 깊게 씁니다 — **프리미엄 집중화가 데이터로 확인된 시장**입니다. Concord의 38만~112만 원(4주) 요금은 참여학생 평균 상단~고소득 가구 밴드에 정확히 위치합니다.
- 1:1 개인과외는 사교육 유형 중 최고 단가 영역입니다. (유형별 참여학생 1인당 월평균: 개인과외 43.9만 원 — 2024년 조사 기준, 2025년 유형별 수치로 실측 교체 대상)

> 출처: 국가데이터처, 「2025년 초중고 사교육비조사」 (2026.3 발표) · 정책브리핑. 유형별 단가는 교육부·통계청 2024년 조사.

#### 핵심 문제 — 공급 과잉 ↔ 검증된 공급 희소

강사의 실제 실력·성실성·학생 궁합은 수업을 몇 주 진행해야만 드러나는 경험재입니다. 학부모는 계약 시점에 학력·사진·자기소개라는 빈약한 신호만 보고 의사결정을 강요받습니다. 공급이 100명이어도 학부모가 신뢰할 수 있는 '검증된 공급'은 0명에 수렴하고, 검증 비용은 각 가정이 매번 처음부터 중복 지불합니다. 이 **검증 갭**이 Concord가 공략하는 지점입니다.

| 문제 | 실체 | 부담 주체 |
|------|------|-----------|
| 검증 비대칭 | 학부모가 사전 검증할 수단 없음 | 학부모 (매 계약마다 검증 비용 중복 지불) |
| 매칭 실패 비용 | 재탐색·계약해지·환불 분쟁, 학습 공백 | 학부모·학생 |
| 관리 부재 | 매칭 이후 진도·과제·성적 변화가 확인 불가 | 학부모(불안·이탈), 강사(부당한 평판 리스크) |

강사 측 2차 비용도 큽니다 — 기존 중개앱 수수료 20~30%, 불안정한 수요와 자기 홍보 부담, 출결·정산·소통 등 비교육 행정, 스펙·외모 중심의 평가 왜곡.

#### 기존 대안의 한계

| 대안 | 대표 서비스 | 한계 |
|------|-------------|------|
| 개인과외 중개앱 | 김과외, 숨고 | 강사 목록 나열만 제공. 검증·매칭·사후 관리 부재, 학부모 셀프 검증, 양측 수수료 |
| 비대면 태블릿 과외 | 콴다과외, 설탭 | 원격 수업. 대면 수요(특히 초·중등) 미충족, 매니저 밀착 관리 부재 |
| 학원·교습소 | 대형 학원 | 1:1 맞춤성 낮음, 일괄 진도, 학생당 케어 시간 부족 |
| 지인 소개·단체방 | — | 검증 0, 분쟁 시 보호 장치 0 |

**결론**: "검증된 대면 1:1 + 전담 매니저 학습관리"를 동시에 제공하는 사업자는 국내 시장에 부재합니다.

#### 왜 지금인가

- 프리미엄 집중화 — 총액 감소 국면에서도 참여 가구의 1인당 지출은 증가. 검증된 서비스에 대한 지불 의향이 확인됩니다.
- LLM API 보편화 — 수업 외 학습 공백을 저비용으로 메울 수 있어 대면 수업 + AI 학습 지원 결합이 가능해졌습니다.
- 결제·클라우드 인프라 성숙(토스페이먼츠·Vercel·Supabase) — 소규모 창업팀도 안정 운영이 가능합니다.
- 학부모의 디지털 학습관리 앱 수용성 상승.

### 2-2. Solution — 검증·매칭·관리를 플랫폼이 대신

**"검증·매칭·관리를 플랫폼이 대신 떠안고, 그 편익을 프리미엄 마진으로 회수합니다."**

학부모가 개별로 부담하던 ①검증 ②탐색·재탐색 ③관리·모니터링 비용을 플랫폼이 집합적으로 단 한 번 수행해 모든 수요자에게 재사용시키는 구조입니다. 학부모는 검증된 강사를 매니저에게 배정받고 이후를 앱으로 관리받으며, Concord는 수업료 수취액과 강사 정산액의 차액을 매출로 수취합니다.

| 축 | 해결하는 문제 | 상세 |
|----|---------------|------|
| ① 강사 직접 검증 | 검증 비대칭 | 서류 심사(학력·경력·과목 증빙) → 대면 면접 → 범죄경력조회 → 합격자만 등록. 검증 결과는 모든 수요자가 재사용 |
| ② 전담 매니저 배정 | 탐색·미스매치 비용 | 대면 심층 상담(목표·과목·학습 스타일·일정) 후 매니저가 최적 강사를 직접 배정. 추천 이유를 함께 안내하고 미스매치 시 무료 재매칭 |
| ③ 디지털 학습 관리 | 학습 투명성 부재 | 캘린더 학습 플랜 · 숙제 자동 분배 · AI(Claude) 즉시 답변 + 강사 답변 이중 구조 · 진도·과제 실시간 열람 |

#### 서비스 플로우

| 단계 | 주체 | 시스템 상태 |
|------|------|-------------|
| 1. 상담 신청 또는 즉시 결제 | 학부모·학생 | 웹/앱 완성 |
| 2. 매니저 자동 배정(결제 시 대표 매니저) 또는 배정 대기 | 시스템 | 구현 완료 |
| 3. 매니저의 대면 심층 상담 | 매니저 | 상담 이력·CMS 완성 |
| 4. 매니저의 강사 직접 배정 (추천 이유 함께 안내) | 매니저 | 매칭 기능 완성 |
| 5. 강사의 첫 수업일 설정 및 수업 시작 | 강사 | 완성 |
| 6. 주간·4일 단위 숙제 자동 분배(가중치 기반) · 반복 템플릿 재사용 | 시스템·강사 | 완성 |
| 7. 학생 질문 → AI 즉시 답변 + 강사 답변 | 시스템 + 강사 | Claude API 연동 완료 |
| 8. 학부모의 진도·과제 실시간 열람 | 학부모 | 완성 |
| 9. 월말 강사 정산 (시급 30,000원/h) | 시스템 | 완성 |

#### 부수 문제 흡수 → 경쟁 해자

1. **재탐색 비용 → 매니저 재배정**: 강사 교체 시 학부모는 아무것도 하지 않습니다. 매니저가 즉시 재배정합니다 (전환 비용 ↓ → 이탈률 ↓).
2. **학습 투명성 → 데이터 자산화**: 일별 플랜·질문·완료율 데이터가 누적될수록 락인이 강해지고, 향후 개인화 추천의 학습 데이터가 됩니다.
3. **강사 수수료·행정 부담 → 시급 보장 + 행정 대행**: 안정적 시급과 장기 인센티브(차등 시급 프리셋 32,000/34,000/40,000원, 관리자 지정)를 보장하고 결제·정산·소통을 대행합니다 — 우수 강사가 머무는 공급 측 해자.
4. **평가 왜곡 → 지속성·성과 기반 대우**: 외모·스펙이 아니라 수업 지속성·성과가 강사 대우를 결정합니다.

#### 이미 구현된 제품 — 실행 리스크가 낮습니다

대다수 예비창업 아이템이 기획서·와이어프레임 단계인 것과 달리, Concord는 웹 플랫폼과 모바일 백엔드가 실서비스 수준으로 완성되어 있습니다.

### 2-3. Scale-up — 시장·확장 로드맵

#### 시장 규모 (TAM/SAM/SOM)

| 구분 | 규모 | 근거 |

## 4. 대표 제안 — 실행 계획과 의사결정 요청

### 4-1. 지금 무엇을, 왜

1. **지금이 파일럿 개시 적기** — 제품 리스크가 제거된 상태이므로, 자본은 개발이 아니라 서울·동탄 1~2개 동 반경 집중 파일럿에 투입합니다.
2. **공급(강사) 채용을 수요 모집보다 2~6주 먼저** 가동합니다 (모집 후 매칭 실패가 최대 유지 리스크).
3. **CAC ≤ 20만 원 채널만** 파일럿에서 사용하고, 주간 계측으로 2주 무반응 채널은 교체합니다.
4. 지원금 1억 원 확보 시 인건비·마케팅·모바일 앱에 배분해 **12개월 내 자립**을 목표합니다.

### 4-2. Go-to-Market — 4트랙

전 채널 1~2개 동 반경 집중. 콜드스타트 순서 준수: 증거(후기·사진) 제작 → 무료·저비용 채널 → 후기 3건+ → 유료 채널.

| 트랙 | 대상 | 우선순위 / 가동 | 핵심 채널 | CAC 가설 |
|---|---|---|---|---|
| **T1 학생** | 사용자·가정 내 추천 | 1순위 | 숏폼·AI 무료체험 → "부모님께 보내기" | 콘텐츠 비용 |
| **T2 학부모** | 결제자(본진) | 2순위 | 네이버 SA(로컬 키워드)·카카오 CRM·당근 비즈프로필 | 결제 CAC 20~50만 |
| **T3 강사** | 공급(최선행) | 3순위 / 수요보다 2~6주 선행 | 채용 공고 SEO·재직 강사 추천(보너스 10만) | 건당 10만 |
| **T4 매니저** | 운영 인력 | 4순위 / Gate 2 이후 | 맘카페·당근 구인(지역) | ≈0 겸용 |

- 예산: 파일럿 자력 월 30~50만 → 성장기 월 100~300만 → 지원금 마케팅비 2,500만.
- 규율: 채널별 주간 계측, 2주 연속 리드 0 → 채널 교체. 학생 트랙 성패는 "부모님께 보내기 → 상담 신청" 단일 지표로 판정.
- 공급 채널 상세: 대학 커뮤니티(에브리타임) 모집 공고, 대학원생·교직 경력자 우선, 지인 네트워크 영입·소개 보상.

### 4-3. 90일 실행 로드맵

| 기간 | 마일스톤 |
|---|---|
| **Week 1~3** | 선행 자산 제작(후기·사진·GA4/UTM·카카오 채널) · 강사 채용 파이프라인 가동(수요보다 선행) |
| **M1** | 집중 지역 무료·저비용 채널 개시 · 첫 상담→매칭→첫 수업 플로우 실주행 · 파일럿 학생 확보 |
| **M2~3** | 후기 3건+ 확보 후 유료 채널(네이버 SA·당근) 소액 테스트 · 활성 5명(BEP) 도달 |

### 4-4. 의사결정 요청

1. **파일럿 개시 승인** — 집중 지역 확정, M1 착수 여부 및 자력 마케팅 예산(월 30~50만) 배정
2. **강사 선행 채용 착수** — 수요 모집 전 강사 파이프라인 가동 승인
3. **매니저 채용 시점** — Gate 2(활성 학생 임계) 도달 시 1~2명 채용안
4. **지원금 신청 방향** — 예비창업패키지 1억 기준 배분안(§3-6) 확정
5. **문서 직접 입력 항목** — 대표자 프로필·창업 형태 `[기재 필요]` — 이 정보만 채우면 지원사업 문서가 즉시 제출 가능 상태가 됩니다.

### 5-1. 공개 페이지

히어로 → 문제 제기 → 검증/매칭/관리 3단 약속 → 프루프 카드 → 상담 CTA의 단일 전환 퍼널. 요금제(8개 플랜)·검증 통과 강사만 노출되는 강사진·습관·태도 변화 중심의 후기·FAQ·약관·개인정보·환불정책 페이지까지 편입되어 결제·분쟁 대응의 기본 골격을 갖췄습니다(정식 법률 검토는 별도 진행).

### 5-2. 학생 여정

대시보드는 학습 단계(상담대기 → 매니저 배정 → 매칭 진행 → 배정 확인 → 첫 수업 대기 → 수업 진행)에 따라 다른 화면을 보여주며, 각 단계가 실제 DB 상태에서 자동 산출됩니다.

- **배정 확인 — 이유를 설명하는 매칭**: 매니저가 배정한 강사가 추천 이유("학생 성향에 맞춰 추천드립니다")와 함께 안내됩니다. 일방 통보가 아니라 왜 이 선생님인지 설명하는 매칭이며, 미스매치 시 무료 재매칭을 보장합니다.
- **수업 진행 대시보드**: 캘린더 학습 플래너(날짜별 할 일, "이전 날에서 복사") · 담당 선생님 카드 + 매니저 케어 기록 · 선생님 코멘트와 학습 목표 · 질문 스레드를 한 화면에 제공합니다.
- **AI + 강사 질답**: 모르는 문제를 올리면 Claude AI가 즉시 1차 답변하고 담당 강사가 이어서 확인·보강합니다. "밤에 질문해도 방치되지 않는다"의 실체이자, AI 토큰 = 원가 통제 가능한 부가가치입니다.
- 결제(토스 서버 검증)·결제 내역·계정·알림 화면 완비.

### 5-3. 강사 · 매니저 · 관리자

- **강사 포털**: 승인 상태·프로필·담당 학생 관리. 매니저 전용 기능은 권한 게이팅으로 분리됩니다.
- **매니저 포털**: 상담 관리 → 강사 후보 카드에서 담당 과목 매칭 → 매칭 이유 입력(학생 화면에 그대로 전달) → 모니터링(진행률·이상징후). 최고매니저는 강사 승인 권한 보유.
- **최고관리자**: 학생·강사·매칭·결제·정산(시급 30,000원 기준)·지표·퍼널·감사 로그·CMS·데이터 콘솔 — 1인 운영에서 다인 운영으로 확장할 때 필요한 통제 인프라가 선제 구축되어 있습니다.

### 5-4. 모바일

전 페이지 반응형으로 모바일 웹 동일 기능 제공. 네이티브 앱은 백엔드 API 58종 완성 위에 학생용 프론트가 개발 후반 단계로, 학부모 모드와 스토어 출시는 지원금 확보 시 완성합니다.

캡처 커버리지: 공개 12 · 학생 10 · 강사 8 · 매니저 6 · 최고매니저 2 · 최고관리자 11 — 총 49페이지 × 데스크톱/모바일 = **98장**.
