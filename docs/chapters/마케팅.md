## 1. 전략·원칙

### 1-1. 전제 (모든 트랙 공통)

1. **구매자·사용자 이중 구조.** 돈은 학부모가 내고(구매자), 쓰는 것은 학생이다(사용자). 학생 트랙의 목표는 직접 결제가 아니라 "엄마, 이거 봐봐"라는 가정 내 추천과 유지율. 우선순위 ①학생은 "학생을 통해 학부모에 도달하고, 학생 만족으로 유지율을 지킨다"로 해석한다.
2. **공급은 수요에 선행.** 마케팅 우선순위는 ①학생 ②학부모 ③강사 채용 ④매니저 채용이지만, 가동 시점은 강사 채용이 학생·학부모 모집 파도보다 **2~6주 먼저**. 모집해 놓고 매칭 못 하면 유지 실패로 전이된다.
3. **콜드스타트 순서.** 증거(후기·사진·페이지) 없이 유료 광고 금지. 자산 제작 → 무료·저비용 채널 → **후기 3건+** → 유료 채널.
4. **지역 집중.** 전 채널에서 권역 1~2개 동 반경 우선 타깃. "전국에 얕게"는 이 BM에서 마케팅비 소각이다.
5. **CAC 규율.** 파일럿은 CAC ≤20만 채널만. 채널별 주간 계측, **2주 연속 리드 0이면 채널 교체, CAC가 2개월 연속 40만 초과면 채널 중단.**
6. **브랜드 보이스.** 차분한 확신, 과장 금지, 수치는 근거 보존. 상세는 §3.

### 1-2. 유입 상한 = 오너 처리용량

상담 첫터치 수행자는 오너 1인. 마케팅 유입은 오너 월 처리용량(상담 1건당 대면+매칭+CS 소요 × 가용시간)으로 역산해 상한을 둔다 — 가설 월 8~13건. 유입 채널 총합이 상한을 초과하면 확대 채널을 일시 중단한다. 번아웃은 사업 정지다.

- **상담 SLA 즉시알림**: 상담 신청 → 오너 폰 즉시알림(텔레그램/카카오워크 웹훅, 무료). 목적은 처리량 증대가 아니라 **누락 방지** — 1시간 내 첫터치가 전환을 좌우한다. [P]
- 확대성 채널(지식iN·당근 광고 등)은 이 상한 아래에서만 가동.

### 1-3. 리퍼럴 엔진 — 유일한 저CAC 성장축

튜터링 업계 벤치: 리퍼럴 CAC $20~80 vs 유료광고 $100~350. 만족 학부모 20~35%가 최소 1가정 소개, 소개 리드의 30~50%가 등록, 소개 가정은 25~40% 더 오래 유지, 소개의 60~70%가 같은 학교·동네에서 발생한다.

- **비가격 우대만.** 할인·금액·평점은 일절 없음(세계관 위반). 우대 후보(오너 확정 대기): ①소개자·피소개자 우선 상담 배정 ②담당 매니저 지정 연속성 보장 ③형제 매니저 연속성 ④소개 가정 우선 강사 풀 접근. 요금표 불변. [P 설계 → A 발동]
- **만족 피크에 요청.** 트리거 4개 — ①첫 달 리포트 발송 직후 ②시험 성적 확인 직후 ③재결제 시점 ④종료·졸업 시(관계 정리 후기 — 의외로 가장 진심). 앱 내 직접 수집 금지 → 매니저 카톡 경유.
- **같은 학교·동네 프레이밍.** 소개 요청 스크립트에 "같은 학교 학부모께"를 명시 — 지역 밀도 플라이휠과 리퍼럴을 한 벡터로.
- 학생 버전: 친구 가입 시 양쪽 기프티콘(5천 원) — 결제 아닌 가입 기준이므로 소액. [A, 소프트런칭]
- 강사 버전: 재직 강사 추천이 최고 품질 공급 채널(유유상종). 추천 강사 최종 합격+첫 수업 개시 시 10만. [강사 3명+ 이후]
- 다자녀: 첫째 재학 6개월+ 가정에 신학기 직전 둘째 상담 제안 1회 — "같은 매니저가 이어서 봅니다" 연속성만, 할인 0. [A]

### 1-4. 계측 게이트 — 무계측 채널 가동 금지

- 모든 링크에 UTM 규격: `utm_source`(instagram / youtube / tiktok / naver_blog / naver_sa / naver_place / kakao_ch / kakao_ad / daangn / cafe / band / offline_qr-{장소} / referral) · `utm_medium`(organic / cpc / crm / event / print) · `utm_campaign`(`{트랙}-{시즌}` 예: `parent-c2-yebigo1`, `student-always-aidemo`, `recruit-teacher-summer`).
- GA4 + 전환 계측 없이는 어떤 채널도 가동하지 않는다. 전화·카톡·폼 각각 전환 이벤트 분리. 매니저 상담 결과 기록으로 오프라인 스티칭.
- **주간 리포트 양식** (월요일): 채널 | 노출 | 방문 | 리드 | 상담 실시 | 결제 | CAC | 판정(유지/증액/수정/중단) + 코멘트 3줄(배운 것 1 · 바꿀 것 1 · 리스크 1).
- 월 1회 채널별 CAC 표 갱신 → 재무계획 가정 대체. 소재·카피의 수치 주장은 근거 파일 보존, "500+/98%" 류 미검증 수치 사용 금지.

### 1-5. 포지셔닝 — 대면·밀도·큐레이션

대외 소구의 무게중심은 **대면·밀도·큐레이션**. 대면 상담·직접 면접은 비대면 대량매칭 경쟁사(설탭·밀당)가 구조적으로 못 하는 것 — 최강 차별화 해자다. AI는 대외적으로 "강사 도구·학습 보조(베타)"로 이중화(IR의 에듀테크 밸류는 내부 문서로 보존). 검증은 마케팅의 메인이 아니라 요소 중 하나 — 공포마케팅 과잉 경계.

**설탭 벤치마크 결론** (흡수/제외 판정 요약):

- 채택: 상담 수렴형 CTA(전 버튼이 상담 한 곳으로) · 초저마찰 공개 폼(학년·과목·연락처·시간·약관, 이름 없음, "단 5초") · 하단 고정 CTA+환불 툴팁 · 리스크 제거 3종(첫 수업 100% 환불·교체 0원·상담만 해도 진단 무료) · 큐레이션 카드(디렉터리·개별 프로필 제거, 카드 버튼 → 상담) · 숫자 각주 형식(실데이터만) · 가격 앵커("월 38만원~" + 상세는 /pricing) · Q&A 반박형 신뢰 섹션 · 성적 변화형 후기 카드.
- 조정: 긴급성 배너(이모지 제거·절제 문구·CMS 토글) · 카운트업(실수치만, 작으면 문구로 대체) · 학생 실명(이니셜 표기).
- 제외: 검증불가 통계 차용 · 명예의전당 · 인강 번들 · 손글씨 개인화 히어로.
- 리듬 패턴: `기능 설명 → 통계 증거 → 학부모 후기` 삼박자 반복.

### 1-6. 금지 사항 (신뢰 해자 보호)

1. 맘카페·커뮤니티 위장 후기·어뷰징 금지 — 위장 후기는 과거 180개 카페·70억 매출 규모 경찰 적발 전력이 있는 즉사 리스크. 적발 시 지역 커뮤니티에서 회복 불가.
2. 대가성 후기·체험단은 표시광고법상 표기 의무 준수.
3. 학생 대상 소재에서 성적 보장·공포 소구("이러다 뒤처집니다") 금지.
4. 미성년자 개인정보 수집 최소화 — 학생 가입 플로우는 법정대리인 동의와 정합.
5. 경쟁사 비방 금지 — 비교는 사실 표(검증 항목 유무)로만. 학원·셔틀을 나쁘게 그리지 않는다("우리 애에겐 다른 방식" 프레임까지만).

### 2-2. 콘텐츠 엔진 — 숏폼 (릴스·숏츠·틱톡) [P]

**필러 4개** (모든 소재는 이 중 하나): P1 공부 실전(학생, 도달·팔로우, 40%) · P2 제품 데모(AI 질답·숙제 분배·리포트 시연, 25%) · P3 신뢰 비하인드(면접 과정·매니저의 하루·합격률 — 신뢰와 채용 브랜딩 겸용, 20%) · P4 사람 이야기(강사 인터뷰·동의된 가정 후기, 15%).

**스크립트 구조**: 훅(0~3초, 자막 큼) → 몸통(3~20초, 포인트 최대 3개) → CTA(3초, "프로필 링크에서 무료 진단").

### 2-13. 후기 자산 루프 · 랜딩 CRO · 위기 대응

A/B 백로그 (월 1개 — 트래픽이 적으므로 큰 차이만 검정): ①히어로 감정층("챙기는 사람을 두세요") vs 기능층("검증된 선생님 매칭") ②폼 필드 3 vs 5 ③보증 노출 위치(히어로 vs 결제 직전) ④요금 표기: 8플랜 매트릭스 vs 3패키지 프레임 ⑤CTA "상담 신청" vs "우리 아이 진단받기".

## 3. 브랜드 보이스 가드 — 발행 전 체크리스트

모든 소재는 발행 전 이 체크리스트를 통과한다(카피 헌법 원문: `BUSINESS_DIRECTION.md` §12~13). 담당자는 자가 감산 패스 1회 후 발행 — AI 초안은 항상 오너 기준보다 요소가 많다. 위반 소재 발행 금지, 오너 취향 판단이 걸린 소재는 브리핑 후 확정.

**문장**
- [ ] 평서 확언 "~합니다" 종결. 느낌표 0 · 의문문 0(훅 제외) · 이모지 0.
- [ ] 주어는 "우리는" — 회사명 3인칭보다 1인칭 복수 선언체.
- [ ] 최상급("최고의")은 클라이맥스 1회만. 평소 문장은 절차의 사실("대표가 직접 만나 면접합니다")로 신뢰를 만든다.
- [ ] 헤드라인은 한 줄. 줄바꿈은 의미 단위가 두 개일 때만. 2박자 대구 리듬.
- [ ] 숫자는 구체·최소("주 1회·3시간"). 총 시간 환산·합산·할인율 등 파생 수치 노출 금지.
- [ ] 조건·단서는 본문이 아니라 각주로 격리("*환불정책 참고").
- [ ] 도입·설명 문장 금지("이런 일들이 실제로 있었습니다" 류) — 본문이 바로 등장.
- [ ] 인용(뉴스·후기)은 원문 그대로 — 패러프레이즈는 진정성을 깎는다. 자기 목소리와 인용을 섞지 않는다.
- [ ] CTA만 해요체/명사형("선생님 추천받기"). 헤드라인 확언체 + CTA 해요체 투트랙.

**세계관·소재**
- [ ] 비교·선택·평점·수락 강조·할인 UX 없음 — 큐레이션이지 마켓플레이스가 아니다.
- [ ] 성적 보장·공포 소구("이러다 뒤처집니다") 없음. 공포(뉴스) 직후엔 반드시 효능감 문장(우리의 행동).
- [ ] 수치 주장은 근거 파일 보존, 미검증 수치("500+/98%" 류) 없음.
- [ ] 검증은 뱃지 3종 나열이 아니라 담백한 절차 서술("면접과 범죄경력조회를 통과한 선생님만") — 뱃지 나열은 오너가 실제 제거시킨 짜침 판정 항목.
- [ ] 박스-안-박스 없음 — 문구는 배경 위에 직접. 할인률 뱃지·검정 프로모션 배너 없음.

**뉴스 스크롤텔링 (공포 소재 사용 시)**
- [ ] 헤드라인 원문 그대로, 3개만, 실명 마스킹.
- [ ] 담백한 공감 문구만 — 설명 멘트 금지.
- [ ] 스킵 허용, 세션당 1회 재생, 총 7초대.

**후기·인용 (정반대 문법)**
- [ ] 전부 다른 사람이 쓴 것처럼 각기 다른 말투·질감. 반말체 금지.
- [ ] "기존 과외는 ~이 불만 → 지금은 ~이 좋다" 구조. 성향 매칭·안전 가치가 스며들게.
- [ ] 실제 학원 후기 말투 학습 후 작성. 오탈자·구어체를 다듬지 않는다. 파일럿 전까지 임시, 실 후기로 교체.
- [ ] 브랜드는 균질하게, 빌린 목소리(후기·인용)는 불균질하게.

### 4-4. 홈·공개 페이지 카피 대안 — **코드 동결 · 오너 결정 사안**

> 공개 페이지(홈·pricing·tutors·reviews·faq·login)는 코드 수정 금지. 아래는 오너 향후 결정용 문안 은행이며 실행 지시가 아니다. 채택 시 CMS 값 교체로 적용 가능(코드 구조 변경 불필요). ★ = 추천안(제안일 뿐, 결정은 오너).

**핵심 10곳 — 1차안 (경구·감정 곡선용)과 2차안 (담백·사실 기반)**

사용 가이드: 감정 곡선이 필요한 곳(스크롤텔링 내부)은 1차 계열, 정보·신뢰가 필요한 곳(검증·관리·리포트·CTA)은 2차 계열. 페이지 전체를 한 계열로 통일하지 말 것 — 비율 약 2:8(경구:사실)이 오너 원문 분포와 일치.

1. **히어로 헤드라인** (현재: "학생마다 맞는 / 선생님이 다릅니다")
   - 1차: ①좋은 선생님이 아니라, 맞는 선생님입니다 ★ ②선생님이 다르면, 공부가 달라집니다 ③아이에게 맞는 선생님은 따로 있습니다 ④맞는 선생님을 만나면, 아이가 달라집니다 ⑤우리는 선생님부터 다르게 고릅니다 ⑥공부보다 먼저, 선생님이 맞아야 합니다 ⑦아이마다, 맞는 선생님이 다릅니다 ⑧성적을 바꾸는 건 결국 선생님입니다 ⑨어떤 아이인지 먼저 묻고, 선생님을 정합니다 ⑩아이를 알면, 선생님이 보입니다
   - 2차: ①직접 만나 검증한 선생님을, 성향에 맞춰 배정합니다 ★ ②상담으로 성향을 파악하고, 맞는 선생님을 배정합니다 ③학생 성향에 맞춰 선생님을 배정하는 과외입니다 ④매니저가 상담하고, 선생님을 직접 배정합니다 ⑤검증된 선생님을, 아이에 맞춰 배정합니다 ⑥아이에게 맞는 선생님을 찾는 일부터 시작합니다 ⑦방문 상담으로 시작하는 1:1 맞춤 과외 ⑧성향을 알고 배정하면, 수업이 달라집니다 ⑨학생을 파악한 뒤에, 선생님을 정합니다 ⑩잘 맞는 선생님은 상담에서 시작됩니다
2. **스크롤텔링 도입** (현재: "과외는 많은 학생에게 최고의 해결책이지만..")
   - 1차: ①과외는 답입니다. 누구에게 맡기느냐가 문제입니다 ★ ②과외는 좋은 선택입니다. 문제는 그다음입니다 ③1:1 과외는 여전히 가장 빠른 길입니다. 그런데, ④과외만큼 확실한 방법은 없습니다. 다만, ⑤가장 좋은 수업은 1:1입니다. 가장 어려운 것도 1:1입니다 ⑥많은 학부모가 과외를 선택합니다. 그리고 걱정을 시작합니다 ⑦과외의 효과는 모두가 압니다. 그런데 그 시작은 늘 불안합니다 ⑧성적을 올리는 가장 확실한 방법이지만, ⑨과외는 시작일 뿐입니다 ⑩좋은 과외와 나쁜 과외의 차이는, 수업 전에 정해집니다
   - 2차: ①과외를 결정하고 나면, 더 어려운 결정이 남습니다 ★ ②과외는 효과가 큽니다. 그만큼 누구를 만나느냐가 중요합니다 ③좋은 선생님을 찾는 일은 여전히 학부모의 몫입니다 ④1:1 수업의 효과는 선생님에 따라 달라집니다 ⑤선생님을 정하는 기준은 대부분 학력뿐입니다 ⑥대부분의 과외는 소개로 시작됩니다. 검증 없이 ⑦과외에서 가장 중요한 결정은 시작 전에 있습니다 ⑧과외 자체는 문제가 아닙니다 ⑨학력 말고는 확인할 방법이 없었습니다 ⑩어떤 선생님이 올지는, 만나기 전까지 알 수 없습니다

### 5-3. 캠페인 3종

- **여름 런칭 (7~8월)**: 목표 상담 30건 · 결제 8~10명 · 후기 3건. 메시지 "여름 6주가 2학기를 결정합니다"(확언체). 채널 믹스 — 지인·소개 웨이브 + 블로그 시즌 글 4편 + 라운드테이블 1회 + 스터디카페 2곳. 유료 광고 없음.
- **예비고1 (11/20~2월, 연중 최대)**: 개시일 수능 다음날. 메시지 "고등 수학은 중등과 다른 게임입니다 — 겨울 로드맵을 먼저 보세요." 상품 — 겨울 인텐시브 + 조기예약 + 6개월 약정 시 인상 전 가격 고정. 이 시기에 연 예산 60% 가중 — 검색광고 2배 증액, 예비고1 설명회 2회, 맘카페 시즌 글.
- **신학기 (2~3월)**: 메시지 "새 학년 첫 시험까지 8주." 겨울 코호트의 정규 전환 + 신규 유입 동시 수확.
- **기말 직후 재결제 리추얼** (상시 장치): 기말 종료 = 학사 목표 완주 지점 = 자연 재결제 지점. 매니저·학부모가 다음 학기 목표를 공동 확정 → 목표 완주 서사로 재결제(가격 마찰 아님) + 상위플랜 자연 전환 제안(할인 0) + 주간 리포트로 가치 증거 상시화. 압박 체감 시 "언제든 해지" 훼손 — 리텐션은 재무 민감도 1위.
