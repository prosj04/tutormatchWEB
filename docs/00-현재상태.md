## 2. 제품 — 무엇이 돌아가는가

- **서비스**: Concord — 서울·동탄의 프리미엄 1:1 방문 과외 큐레이션·학습관리 서비스. 전담 매니저가 학생에게 맞는 선생님을 배정하고 수업 이후 학습까지 관리한다. 앱·웹은 운영 도구다.
- **프로덕션**: `https://tutormatch-web.vercel.app` (Vercel `tutormatch-web`, `main` push = 즉시 배포). **v3 개편은 여기에 아직 올라가 있지 않다.**
- **역할 5종**: 학생 / 학부모 / 선생님 / 매니저(+치프) / 어드민.
- **관통 플로우**: 상담 신청·결제 → 치프 자동 배정 → 대면 상담 → 매니저가 선생 배정(미확인 3일 후 자동 확정) → 첫 수업 → 숙제 자동 분배(템플릿) → 수업 확인 제도(자동완료 폐지, 선생님이 완료/사유 확인, 비과실은 마지막 수업으로 이월, 3자 공지) → 월간 AI 리포트 → 빌링키 자동갱신·정산.
  - ⚠️ 수락 버튼은 코드상 존재하나 **형식적 절차** — 마케팅·UI 에서 강조 금지 (2026-07-08 확정).
  - ⚠️ **학생이 직접 강사 교체를 요청하는 UI 는 앱·웹 어디에도 두지 않는다** (2026-08-03 오너 결정). 교체는 매니저 대면 상담에서만.
- **모바일**: 통합 4역할 앱(Expo). 스토어 제출은 오너 결정 대기 — [`STORE_SUBMISSION_2026-07.md`](STORE_SUBMISSION_2026-07.md).

- **단계**: 출시 전 파일럿 준비. 코드는 결제→정산까지 관통 가능. 더미·샘플 데이터 존재(공개 노출은 `[sample]` 접두사 필터로 차단).

- **마케팅**: 4트랙(①학생 ②학부모 ③강사 ④매니저) → [`20-마케팅.md`](20-마케팅.md). 공급(강사 채용)이 병목이며 유입보다 6주 앞선다.
